# Spikes

A spike answers one question with the cheapest experiment that can answer it and is judged
against a number written down before the experiment ran. The shape of a row — question, cheapest
experiment, exit criterion, status, machine — is the `spike-contract` skill; this folder holds the
records, one file per spike, named for the date it was decided and the question it settled.

A spike record is history. It is not revised when a later measurement disagrees: the later
measurement gets its own record, and the two are read in order.
