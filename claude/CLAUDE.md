# Global instructions

These instructions come from a Model Citizen checkout; its topic rules and chosen preference
variants load automatically alongside. Each rule carries its operative lines and a pointer to the
skill holding the reasoning and examples — read that skill before working in its area. Placement of
a new instruction is the ladder in `harness-authoring`; the layers are in `docs/how-it-works.md`. A
rule about repositories, tests or pull requests is about code work; elsewhere it does not apply.
