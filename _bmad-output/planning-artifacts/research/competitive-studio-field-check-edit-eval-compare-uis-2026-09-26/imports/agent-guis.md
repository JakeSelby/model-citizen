## Verdict
No GUI measures whether a CLAUDE.md/rules/hooks change helped. The only primary-source config-efficacy tool is Claude Code's CLI `claude plugin eval` (with vs without plugin, HTML report), scoped to plugins/skills; goose bench may have covered multi-config evals but is unconfirmed in the current tree.
