- (decision) The Studio should feel clean and bright, like an operational dashboard. Mantine is the preferred UI system, subject to architecture and licensing validation before implementation.
- (decision) The Studio opens on a hub landing page with alerts, notifications, reports, links, and aggregate measures; every aggregate drills into the underlying report and evidence.
- (decision) The hub includes an AI-generated overview of recent system health and performance that highlights issues and anomalies and produces an advisory list of things to investigate. The overview is not the system of record and must link each claim to its source evidence.
- (decision) The AI health overview refreshes automatically when relevant source data changes. Refresh is event-driven rather than polling; the prior assessment remains visible and marked stale until regeneration finishes.
- (decision) AI overview is opt-in, provider-neutral, and pluggable. It reuses the developer's configured development model or tool rather than requiring a Studio-specific AI account; the UI exposes provider, model, provenance, and spend limits without storing provider credentials.
- (decision) The Studio uses five stable navigation areas: Hub, Configure, Experiments, Reports, and Activity. Drafts are a global working state. The AI investigation queue appears on the Hub and deep-links to the relevant report or configuration.
- (decision) The chosen Hub visual direction is direction-briefing: an airy operational briefing with horizontal navigation, the AI assessment as the primary surface, report aggregates beside it, and drafts, runs, alerts, and notifications below.
- (decision) The Studio uses the Clear theme: quiet teal, cool neutrals, restrained semantic status colors, a light-first default, and a matching dark theme.
- (event) Licensing review approved @mantine/core and @mantine/hooks 9.6.3 for the permissive-commercial stance: both MIT; the inspected resolved tree was MIT, 0BSD, or dual MIT/CC0. Exact lockfile, notices, bundle contents, and deterministic rebuild remain W0 implementation gates.
- (decision) Mantine owns the Studio UI primitives, with DESIGN.md semantic tokens overriding its theme. Implementation waits for the exact dependency lockfile, notices, accessibility checks, and deterministic-bundle spike.
- (decision) Draft saving uses a 750 ms debounced checkpoint for forms; text editors save explicitly with Save or Cmd/Ctrl-S.
- (decision) Notifications persist across Studio restarts, deduplicate repeated events, support read and dismiss, and never remove their immutable Activity evidence.
- (decision) Automatic AI refresh coalesces evidence changes for 60 seconds, retries transient failures three times with backoff, stops at the daily cap, and always permits manual refresh.
- (decision) Theme follows the system on first open and persists the user's explicit light or dark choice thereafter.
