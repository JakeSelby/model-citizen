## Reproduction

Run `DISABLE_TELEMETRY=1 npx -y skills add JakeSelby/model-citizen --list` against the public
repository. The CLI reports five YAML parse errors and lists only ten of the fifteen skills.
Anthropic's directory validator also rejects one command's YAML frontmatter and two symbolic links
at plugin load or executable surfaces.

## Root cause

Five `description` values use a colon followed by whitespace inside an unquoted plain scalar.
Model Citizen's deliberately small flat-frontmatter parser accepts that text, but a standard YAML
reader treats the suffix as a nested mapping and rejects the document.

The review command similarly leaves a multi-group argument hint containing a colon unquoted. The
plugin manifest names a symbolic output-style path, and `bin/citizen` is itself a symbolic link;
the directory cannot inspect either entry and blocks the submission.

## Acceptance criteria

1. **Given** the Model Citizen checkout, **when** the skills.sh CLI lists it, **then** all fifteen
   skills are present without YAML errors.
2. **Given** a `SKILL.md` description with an unquoted colon-space sequence, **when** the repository
   gate runs, **then** its frontmatter test names the skill and fails.
3. **Given** the five repaired descriptions, **when** the trigger and shape tests run, **then** their
   selection phrases and description budgets still pass.
4. **Given** the plugin checkout, **when** Anthropic's directory validator inspects it, **then** its
   command frontmatter and declared component paths are readable standard files.
5. **Given** either CLI entrypoint, **when** it runs, **then** its command name and checkout
   detection remain unchanged after replacing the `citizen` symlink with a wrapper.

## Design

Rewrite the five sentences as YAML-safe plain scalars and add a narrow lint check for the exact
interoperability trap. Do not add a YAML runtime dependency or change how frontmatter is rendered
for either supported agent.

Quote the complex command argument hint, point `outputStyles` at the canonical regular directory,
and replace the executable symlink with a regular wrapper that loads the same implementation.
Ship the existing Model Citizen mark at the directory's required icon size.

## Regression test

`SkillFrontmatterYamlTests` scans every shipped skill and rejects the plain-scalar pattern that the
registry cannot parse. A local skills.sh listing is the end-to-end acceptance check.

## Dev notes

The public registry clones the repository, so public indexing must happen after the fix reaches the
default branch. Anthropic's directory validator passed the feature branch with no blockers. The
lint is intentionally limited to `SKILL.md` description scalars; it does not claim to be a general
YAML validator. Jake approved bundling this fix into v0.14.1 with fresh native qualification rather
than carrying v0.14.0 evidence through a presentation-only patch.
