## Story

As a solo or small-team agentic developer, I want a Home page with a daily digest and at most five things that need me, so that I open the Studio and know what to do first.

## Context and value

Plan step 6. The queue draws on the other pages: a rule gone silent, a hook gone silent, a draft waiting, a context overage, drift from `/api/overview`. It replaces Hub.

## Acceptance criteria

1. **Given** Studio data, **when** Home opens, **then** it shows the daily digest.
2. **Given** attention items, **when** the queue renders, **then** it shows at most five, each with one action.
3. **Given** each source (silent rule, silent hook, waiting draft, context overage, drift), **when** it holds, **then** an item appears linked to its page.
4. **Given** the route, **when** its API tests run, **then** they cover shape, auth, errors and the five-item cap; node tests and an e2e flow cover Home.

## Design

### Approach

- A Home route composing the other routes' signals; one action per item.

### Decisions and alternatives

- **Five items, one action each:** a queue the user finishes. Rejected: an unbounded feed.

### Do not implement

- New signals not already computed by another page.
