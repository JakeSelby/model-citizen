## Story

As a developer, I want the four-arm bench and factorial screens in the Studio, so that I find which switches matter before paying for a full run.

## Context and value

The v0.16.0 and v0.17.0 engines become catalog suites: the four-arm bench and layer swaps (#802), and the factorial screening runner for switch permutations (#805). A developer picks the switches to screen from the selection page, sees the design's size and spend estimate first, and gets the main effects back.

## Acceptance criteria

1. Given switches picked for screening, then the Studio shows the number of arms and trials and the spend estimate before anything runs.
2. Given a finished screen, then each switch's main effect shows with its interval.
3. Given four arms, then each arm's profile and result are recorded and comparable pairwise.
