## Goal

The Studio is organized by the user's questions, not by the harness's parts: Home, Sessions, seven Harness pages with Efficacy and Settings tabs, Routines, Changes and Evals. Every new signal is computed when the page loads, from logs the harness already writes, and each efficacy row is stamped with the setting in effect at the time.

Completion is observable: the Studio CI suites are green on the branch, and every page shows real data with period-stamped efficacy.

## Scope and requirement coverage

**Information architecture:**

- Home
- Sessions
- Harness: Rules, Stances, Skills, Hooks, Roles, Workflows, Sources, each with Efficacy (default) and Settings tabs
- Operate: Routines, Changes
- Measure: Evals (with Baseline replacing Setup)

**In scope:** the IA shell and redirects, the setting periods module, the two-tab Harness frame, the seven Harness pages, the transcript index, Sessions, Changes, Home, Evals, Baseline, Routines and the retirement of the old pages.

**Out of scope:** the team Steward view, a chat or Ask surface, beginner presets, and any new hook-side recording.

**Requirement coverage:** FR-77 See the whole harness, live; FR-78 Tune in drafts; FR-79 Apply and roll back through the governed path; FR-80 Run any suite; FR-82 Compare runs and judge a change; FR-83 Rule health, usage and proposals.

## Architecture slice

- **AD-11 Local ledgers are the system of record:** every signal is read at page load from `usage.jsonl`, `decisions.jsonl`, `applies.jsonl` and transcripts; no hook or runtime change.
- **AD-3 Reversible configuration ownership:** Settings saves create drafts routed to Changes and apply through the existing governed path.
- Components: `studio/src` nav and pages; `lib/harness_core/studio` routes plus new periods, transcript-index and routines modules.

## Sequencing

- Phase A: the spike, then S1 to S8 (Harness pages first, plan decision 3; four builders at most), then the local review build.
- Phase B: S9 to S13, with the IA sessions run on the review build alongside, not gating it (plan decision 5).
- Phase C: S14 to S16, then S17 last.
- Stories land one PR each into `feature/v0.18.0-studio` (plan decision 2); milestone v0.16.0 (plan decision 1).

## Exit criteria

- Every child closed; the AGENTS.md gate and the Studio workflows green on the branch.
- Every page shows real data with period-stamped efficacy.
- A routine fires on schedule and shows in Routines and on Home.
