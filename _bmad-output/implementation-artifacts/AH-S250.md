## Story

As a harness maintainer, I want an external task set from Harbor, adopted only after a licensing review, so that a bench result cannot merely reflect our own choice of tasks.

## Context and value

Every task in the bench today is our own, so a result could reflect our choice of tasks. An external set checks that. Harbor runs agent benchmarks with per-trial token, cache and cost fields, and its leaderboard asks for at least five trials. Its licence is unverified, so the review comes before any code depends on it.

Traces to NFR-11 and PRD §9 (v0.17.0).

## Acceptance criteria

1. Given `licensing-review`, then Harbor and each dataset used are cleared and recorded before any code depends on them; one that is not cleared stays out, and the story records why.
2. Given a cleared set, then both arms run it at five or more trials, and its per-trial token and cost fields map into the ledger.
3. Given the results, then they carry SM-2's analysis and are reported apart from the internal set.
4. The PRD names the external set through `bmad-prd`, since the text of record does not.
