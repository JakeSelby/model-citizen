## Reproduction

In a scratch home with the harness installed, pass these commands through the Bash hook dispatcher in the default mode and in bypassPermissions:

- `nice -n 5 echo {} > .agent-harness/governance.json`, and the same write behind `env -i`, `env -u X`, `timeout -s KILL 5`, `stdbuf -o0`, `command -p` and `uv run`: allowed in both modes, although bash performs the write. Unwrapped, the governance write asks.
- The same wrapped forms writing the approvals store: allowed in both modes. Unwrapped, the write is denied.
- `env 'X%=1' <command>`, `env X%=1 <command>`, `env 'A B=1' <command>`, `env =1 <command>`, `env 1=1 <command>` and `env -S '<command>'`: the hook emits nothing, so any command passes. `/usr/bin/env` runs the command.

Found by a bash-probed review of #1138; present on main at bdf36de1.

## Root cause

grade-bash stripped a wrapper's name but not its options, so the option or its value became the command word; the recorded redirect into the policy file was attached to that word, which graded 0, and a grade-0 command returned before governance ran. `env` treated only a valid shell name followed by `=` as an assignment, so any other word holding `=` became the command word, and `env -S` was not split at all. [Source: policy/hooks/grade-bash.py]

## Acceptance criteria

1. **Given** a write into a governance policy file behind any of the listed wrappers with options, **when** the dispatcher decides it, **then** it asks in the default mode and denies in bypassPermissions, as the unwrapped write does.
2. **Given** a write into the approvals store behind the same wrappers, **when** the dispatcher decides it, **then** it asks (grade 3) in the default mode and denies in bypassPermissions.
3. **Given** `env` with a word holding `=` that is not a valid name, or `env -S` with a command line, **when** the hook grades it, **then** it grades and governs the command it runs and never emits nothing.
4. **Given** a wrapper option the wrapper does not take, **when** the hook grades it, **then** the wrapped command grades 3.

## Design

A redirect into a file now grades at least 1 whatever wrapper runs it, so a governed write can no longer return before governance. Each wrapper's options come from a GNU/BSD table (value-taking options consume the next word); an option the wrapper does not take grades 3. `env` reads every word holding `=` as an assignment, as env itself does, and splits `env -S` into the command line it holds; an `-S` string with quotes, a backslash or `$` grades 3, since env interprets it itself. Runners such as `uv run` read an unknown option both ways (as a flag and as taking the next word) and grade the worse, so `uv run --frozen pytest` does not start denying. Must not change: the grade of an unwrapped command, and `npx`/`uvx` keep their lenient option handling.

## Regression test

`tests/test_governance_wrappers.py`: each wrapped governance and approvals-store write through the dispatcher in both modes, and each `env` form. On a `git archive` copy of main, 9 of its 10 tests fail (91 subtests); on the branch they pass.
