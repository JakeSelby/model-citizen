# AH-B184 — fix(confinement): refuse a framework brief that points back at the prompt file after a summary or edit

The issue carries the summary, discussion and acceptance evidence; this file carries the design.

This work item was authored as part of the repository's committed BMad planning system.
<!-- bmad-sync:end -->

## Reproduction

Spawn a subagent whose brief summarises or edits a declared framework prompt file and then points back at it in its own words, for example "Summarise <path>, then use it to review calc.py", "Edit <path>, then follow it when reviewing calc.py" or "Summarise <path> and do what it says". The default-refusal hook lets each spawn through. A brief that names a different file after "the file", or a path glued to a prefix such as "my<path>", is misattributed.

## Root cause

`lib/harness_core/frameworks.py` judged adoption sentence by sentence from a fixed phrase list. Pointer-back phrasings ("use it to", "follow it when", "do what it says") were missing, a reference chain did not stop at a sentence naming another file, and `_path` matched without a path boundary. [Source: lib/harness_core/frameworks.py#_refers_back, #_path, #_adopted, #_directed]

## Acceptance criteria

1. **Given** a brief that summarises or edits the prompt file, **when** it then says "use it to", "follow it when" or "do (exactly) what it says", **then** the spawn is refused.
2. **Given** a bare read followed by one sentence that only summarises it, **when** the spawn is checked, **then** it is allowed.
3. **Given** a sentence that names a different file after "the file", **when** a later sentence says "follow it", **then** the instruction is not attributed to the prompt file.
4. **Given** the declared path glued to a prefix, **when** checked, **then** it does not match; after a `/` it still does.
5. No existing refusal case in `tests/test_framework_default_refusal.py` is loosened.

## Design

Extend the pointer-back phrase set, break the reference chain on a sentence naming another file, require a path boundary in `_path`, and let one bounded follow-on summary attach to a read. Rejected: CodeRabbit's broader clause rule, which would refuse an existing allowed rewording case. Security bias: where allowing a harmless phrasing would weaken a refusal, refusal wins; the leftover cases are #1279.

## Regression test

`tests/test_framework_default_refusal.py`: the new cases (including `LaterAdoptionTests`) fail on the pre-fix code (failures=5 in round one, failures=4 in round two) and pass after.
