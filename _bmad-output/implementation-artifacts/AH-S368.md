## Story

As a solo or small-team agentic developer, I want the Studio's navigation grouped by the questions I ask, with every old link still landing somewhere, so that I learn the new shape once and nothing I bookmarked breaks.

## Context and value

Plan step 3. Today's nav (`studio/src/navigation.ts`, `StudioApp.tsx:102-158`) follows the harness's parts. The new IA groups pages as Home, Sessions, Harness, Operate and Measure, and the round-3 mocks' tokens become the theme so every page shares one visual system.

## Acceptance criteria

1. **Given** the Studio, **when** it loads, **then** the nav shows Home, Sessions; Harness: Rules, Stances, Skills, Hooks, Roles, Workflows, Sources; Operate: Routines, Changes; Measure: Evals.
2. **Given** each old route (Hub, Configure, Library, Experiments, Reports/rules, Reports/usage, Reports/trends, Activity, Setup), **when** it is opened, **then** it redirects to its new page as the plan's redirect table maps it, Configure to the matching Harness page's Settings tab.
3. **Given** a page, **when** it renders, **then** it shows the CLI command `navigation.ts` maps to it, moved with the page.
4. **Given** the theme, **when** pages render, **then** the tokens from `studio-mocks/base.css` come from the Mantine theme and no page copies CSS.
5. **Given** the change, **when** `npm --prefix studio test` and `test_e2e_studio_flows` run, **then** they pass, with node tests for the nav and an e2e test per redirect.

## Design

### Approach

- Rewrite `navigation.ts` and the route table in `StudioApp.tsx` for the new groups; new pages may start as placeholders the later stories fill.
- Redirects live in one table so S17 can remove them in one place.
- Move the mock tokens into the Mantine theme once.

### Decisions and alternatives

- **Redirects kept until S17:** old links keep working while pages land one by one. Rejected: removing old routes now.
- **Tokens in the theme:** one source for every page. Rejected: copying CSS page by page.

### Do not implement

- Page content beyond placeholders; the redirect removal (S17).
