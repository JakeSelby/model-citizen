## Story

As a contributor, I want the UI built from pinned source into a committed bundle that CI checks, so that users get the UI without Node and the bundle always matches its source.

## Context and value

The UI source lives in its own workspace, on the stack the architecture decisions name, and its build output is committed where the server serves it, so a curl install needs no Node. Contributors run `npm ci && npm run build`, and a `studio` CI job type-checks, lints, runs the unit tests and checks the committed bundle against its source in the way the reproducible-bundle spike decided.

## Acceptance criteria

1. Given a clean clone with no Node installed, when `citizen studio` runs, then the UI loads from the committed bundle.
2. Given a source change committed without a rebuilt bundle, when CI runs, then the `studio` job fails and names the stale files.
3. Every package that reaches the bundle has a licensing review, an entry in `third-party.json` and a line in `THIRD_PARTY_NOTICES`, and none is copyleft.
4. `citizen lint` and CodeRabbit skip the generated bundle, and `.gitattributes` marks it generated.
5. Dependabot watches the npm lockfile, and the Node version is pinned in one file.

## Design

### Approach

Promote AH-SP017's pinned fixture into the production `studio/` workspace without changing its
dependency tree. Vite emits content-hashed external JavaScript and CSS plus the reviewed dependency
inventory and runtime notices. The bundle is committed under `studio/dist/`; one isolated CI rebuild
compares every emitted path, size and SHA-256 and prints each stale path.

The initial application is the approved Briefing/Clear responsive foundation: five stable routes, a
global Drafts affordance, linked report aggregates, alerts/notifications space and an explicitly off AI
overview. It presents no fixture measure as live evidence. Later stories attach the shared-core data and
controls to these routes.

### Decisions and alternatives

- Keep the exact AH-SP017 dependency versions and lockfile. No package was added or upgraded.
- Use Node's built-in test runner and a small local source linter, avoiding a second unreviewed test or
  lint dependency tree.
- Use hash routing for the initial SPA so page navigation needs no server-side fallback route. Vite's
  content-hashed assets remain external for AH-S282's no-inline-script CSP.
- Preserve upstream licence bytes in the public source directory and copy them into every build. The
  generated inventory remains fail-closed on missing or disallowed licence evidence.
- Replace the three-build spike workflow with the production check: source lint/test/typecheck,
  dependency evidence and audit, then one isolated byte-for-byte rebuild against committed output.

### Do not implement

- Domain APIs, browser authentication and authorization, SSE, run/draft behavior and live data.
- The complete shared component kit and qualification evidence owned by AH-S284 and AH-S315.
- Any new or upgraded third-party package.

### Testing

`npm run lint`, `npm test`, `npm run typecheck` and `npm run build` cover the production source. The
Python manifest tests prove stale-path reporting, fail-closed licensing and workflow wiring; the frontend
contract tests prove hashed committed assets, distributed notices, generated review markers, the sole
`.node-version` authority and Dependabot coverage. The harness lint regression proves normal and staged
discovery skip the generated bundle while still finding the same shape in `studio/src/`.
`studio_bundle_manifest.py verify` performs the same isolated rebuild as CI. The browser regression runs
the committed shell in Chrome under the production CSP and checks wildcard recovery, focus, active-page
semantics, responsive layout, system dark mode, Mantine's nonce and style-prop rendering, and zero CSP
violations.

## Review findings

- Spec review: `.gitattributes` and the generated notice's email exemption did not make `citizen lint`
  skip the whole committed bundle. Resolved with one exact `studio/dist/` discovery prefix shared by
  normal and staged lint paths, plus a regression proving `studio/src/` remains in scope.
- Scope rereview: `package.json` and its lockfile duplicated `.node-version`'s exact value. Removed the
  `engines` mirror and made the contract assert that CI reads the one exact authority.
- Quality review: Mantine runtime styles were blocked, the skip link overwrote HashRouter state, empty
  cards claimed healthy zeros, Clear tokens/system color selection were incomplete, and tests did not
  render the shell. Resolved with a per-response style nonce plus style-attribute-only CSP allowance,
  focus-only skip behavior, wildcard recovery, explicit unavailable states, exact semantic tokens and a
  production-server Chrome regression. The script policy remains `script-src 'self'`.
- Accessibility rereview: the approved dark accent rendered white filled-button text at 1.60:1.
  Enabled Mantine automatic foreground contrast without changing the accent, and made the production
  browser regression calculate a 4.5:1 minimum for filled primary controls in system light and dark.
  The selected foreground tokens measure 7.06:1 in light and 9.22:1 in dark.
