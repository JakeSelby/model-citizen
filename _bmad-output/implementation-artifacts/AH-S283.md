## Story

As a contributor, I want the UI built from pinned source into a committed bundle that CI checks, so that users get the UI without Node and the bundle always matches its source.

## Context and value

The UI source lives in its own workspace, on the stack the architecture decisions name, and its build output is committed where the server serves it, so a curl install needs no Node. Contributors run `npm ci && npm run build`, and a `studio` CI job type-checks, lints, runs the unit tests and checks the committed bundle against its source in the way the reproducible-bundle spike decided.

## Acceptance criteria

1. Given a clean clone with no Node installed, when `citizen studio` runs, then the UI loads from the committed bundle.
2. Given a source change committed without a rebuilt bundle, when CI runs, then the `studio` job fails and names the stale files.
3. Every package that reaches the bundle has a licensing review, an entry in `third-party.json` and a line in `THIRD_PARTY_NOTICES`, and none is copyleft.
4. `citizen lint` and CodeRabbit skip the generated bundle, and `.gitattributes` marks it generated.
5. Dependabot watches the npm lockfile, and the Node version is pinned in one file.
