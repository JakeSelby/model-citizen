# AH-B190 — fix(usage): give Remote Control bridge sessions the context-reset hand-off block

## Reproduction

1. Start a session through `claude remote-control` and work it past `switches.session_handoff_at`.
2. Observed: no stop is blocked and `adherence.jsonl` holds no `context-reset-handoff` emission for it. On the maintainer's machine three bridge sessions since 2026-10-13 ran to 461k, 561k and 922k tokens this way.

## Root cause

`policy/hooks/usage-feed.py` `handoff_enabled()` returns False for every `CLAUDE_CODE_ENTRYPOINT` in `HEADLESS`, so a `claude -p` replay trial is not given an extra turn. A bridge child is launched as `--print --sdk-url …` and its transcript rows carry `entrypoint: sdk-cli`, so the bridge session was exempted as if it were a replay.

## Acceptance criteria

1. **Given** a stop past the hand-off point with `CLAUDE_CODE_ENTRYPOINT=sdk-cli` and `CLAUDE_CODE_ENVIRONMENT_KIND=bridge`, **when** the feed answers it, **then** the stop is blocked and the emission recorded.
2. **Given** the same stop from a headless run (no `bridge` environment kind), **then** it is not blocked.
3. **Given** `HARNESS_HANDOFF_BLOCK=off` in a bridge session, **then** it is not blocked.

## Design

The bridge sets `CLAUDE_CODE_ENVIRONMENT_KIND=bridge` (with `CLAUDE_CODE_BRIDGE_*` variables) in each child it spawns, read from a live bridge child's environment; a `claude -p` run has none of them. `handoff_enabled()` checks the switch first, then an interactive environment kind, then the headless entrypoints. Only `bridge` is named, since no other kind has been observed.

Rejected: reading transcript fields (`promptSource`, `turnOrigin`), which a `-p` run writes the same way; and the desktop app's `CLAUDE_CODE_SESSION_ATTENDED`, which a bridge child does not set. Unchanged: the headless exemption and the switch.

## Regression test

`tests/test_session_handoff.py` `Headless.test_a_bridge_session_is_blocked` fails on the pre-fix hook; `test_another_environment_kind_leaves_a_headless_run_unblocked` and `test_the_switch_can_turn_it_off_in_a_bridge_session` pin AC 2 and 3. The fixture drops an inherited `CLAUDE_CODE_ENVIRONMENT_KIND`, so the suite reads the same inside a bridge session.
