## Story

As a solo or small-team agentic developer, I want a Rules page showing each rule's health per setting period, so that I can see which rules earn their context and try one without.

## Context and value

Plan step 4. Reads `rule_health.report` (`rule_health.py:344`) per period from AH-S369, plus `try_without` and selection. Target artboards `Rules.dc.html` and `RulesSettings.dc.html`.

## Acceptance criteria

1. **Given** rule health data, **when** the Rules page opens, **then** each rule shows its health per setting period.
2. **Given** a rule, **when** try-without is chosen, **then** it routes through the existing `try_without` path, and selection shows on the Settings tab.
3. **Given** the page's route, **when** its API test runs, **then** it asserts period-stamped rows, the response shape, auth enforcement and error cases.
4. **Given** the page, **when** design-judge scores it against its round-3 artboard, **then** the score is at least 7, and node tests and an e2e flow cover it.

## Design

### Approach

- Rows from `rule_health.report` split by periods; Settings tab over selection.

### Decisions and alternatives

- **Read at page load from existing logs:** no hook-side recording (epic scope). Rejected: new recording for this page.

### Do not implement

- Changes to other Harness pages; new hook-side logging.
