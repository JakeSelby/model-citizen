## Goal

Disclose the external services that Claude Directory workflows can contact, what they can send,
and the native-permission boundary so the directory data-handling declaration is accurate.
[Source: README.md#data-and-external-services-in-the-claude-directory-plugin]

## Acceptance criteria

1. **Given** a directory user reviewing Model Citizen, **when** they read the README, **then** it
   identifies GitHub or another configured remote, Claude Code web tools, and explicitly chosen
   services together with the data those calls can send.
2. **Given** those external calls, **when** the privacy boundary is read, **then** it says they are
   user-directed, governed by the selected service, and subject to Claude Code permissions.
3. **Given** the disclosure, **when** the manifest regression suite and repository gate run,
   **then** the required wording remains present and all checks pass.
