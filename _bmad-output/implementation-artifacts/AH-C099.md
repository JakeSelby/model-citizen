## Goal

Prove that resumed native qualification cases match the complete evidence header, including
model and routing, even when the source commit is unchanged.

## Acceptance criteria

1. Changing only `model_run` reruns every settled case at the same source commit.
2. Changing only class routing reruns every settled case at the same source commit and model.
3. Repeating the new header skips its settled cases, without mixing earlier verdicts.

## Design

Extend the existing resume-test helper to accept explicit model and routing. Drive `record()`
through failed original rounds, successful changed-header rounds, and unchanged-header resumes.
Keep routing fixed in the model test so it independently protects the model header field.

## Tasks

- [x] Add model-change and routing-change resume regressions. (AC 1, 2)
- [x] Assert current verdicts, appended headers and repeated-header skips. (AC 3)
- [ ] Complete the full Gate and independent review.
