## Goal

The Studio launches every suite the project runs, whole or down to one test or case, against the
installed version, a release, a branch, a worktree or a draft, each in an isolated profile built from
its target. Logs stream, runs cancel, and every run is kept in a store that indexes the native result
files and can be rebuilt from them. A run that spends usage shows its estimate and caps first.
`citizen runs` gives agents the same launcher.

Completion is observable: one unit test, the full suite, lint and the static figure run from the
Studio with live logs; a draft target leaves the live home byte-identical; deleting the run store and
reindexing restores every run; and no paid run starts without a confirm.

## Architecture slice

- **AD-11 Local ledgers are the system of record:** the run store is an index, never the record.
- **AD-12 Measurement invariants:** targets are built profiles, arms differ only in what is measured,
  and every run records its target.
- **AD-8 Constrained roles run only as isolated role workers:** runs follow the role workers'
  supervision pattern for orphans [Source: docs/role-workers.md].
- **AH-T036's run-store and process decisions.**
