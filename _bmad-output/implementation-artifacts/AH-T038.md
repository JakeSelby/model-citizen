## Goal

Register the silent observer only after an explicit opt-in, and keep benchmark observations in
the benchmark run's own ledger rather than the user's everyday state.

## Acceptance criteria

1. Default sync keeps exactly the existing hook registrations in both managed runtimes.
2. `observation.enabled=true` adds one separate recorder for each supported native event;
   disabling and uninstalling remove only managed entries and preserve user hooks.
3. Nonboolean opt-in values are rejected before sync writes anything.
4. Replay observation records are written through the benchmark runner to the run's own ledger,
   with equally declared observer inputs in both arms and no host-home contamination.
5. Focused tests on both supported Python versions, the full Gate and independent review pass.

## Tasks

- [x] Add validated opt-in configuration and reversible native registration. (AC 1–3)
- [x] Test default, enabled, repeated sync, disable and uninstall behavior. (AC 1–3)
- [x] Integrate benchmark-owned observation collection and declared arm inputs. (AC 4)

## Dev notes

The canonical observer remains separate from lifecycle dispatch. `observation.with_observation`
augments generated native registration in memory only when the boolean switch is true. Sync's
existing reconciliation ownership markers remove observer entries without claiming user hooks.
The benchmark portion must inherit the manifest validation and parity changes in #482 before
adding observer inputs. Sources: `lib/harness_core/observation.py`, `observer.py`, `bin/harness`
sync and diff, `scripts/replay_arms.py` and `scripts/cost_bench.py`.

## Dev agent record

Codex implemented the native opt-in and benchmark-owned collection. Both arms declare and install
the same observer bytes; each native benchmark session writes to a fresh run-owned file and its
real row/error counts are stamped on results. Full validation and independent review remain pending.
