## Goal

Publish an accurate privacy policy for the Claude Directory distribution and make it discoverable
from the plugin manifest and repository landing page so users and directory reviewers can verify
what the plugin reads, sends and retains.
[Source: .claude-plugin/plugin.json]

## Acceptance criteria

1. **Given** the Claude Directory plugin, **when** a user reads its policy, **then** the policy
   distinguishes client-side access from data received by a Model Citizen-operated service and
   accurately describes retention and the separately installed harness.
2. **Given** the plugin manifest and README, **when** a user or directory validator looks for the
   privacy policy, **then** both surfaces link to the committed policy.
3. **Given** the new public metadata, **when** the manifest regression test and repository gate
   run, **then** they pass.

## Tasks

- [x] Add the directory-plugin privacy policy (AC: 1)
- [x] Link the policy from the plugin manifest and README (AC: 2)
- [x] Add and run manifest regression coverage and the repository gate (AC: 3)
