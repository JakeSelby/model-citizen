## Story

As the maintainer, I want the power command to size a design from a pilot at the pass-rate ceiling
under a stated assumption, and every null reported against a pre-registered equivalence margin, so
that the definitive run can be sized from the pilot we have and a null result says how large an
effect it rules out.

## Context and value

The #1144 pilot on pack 1.0.0 passed 35 of 35 attempts in both arms, so `replay_power.py` refused
it: a pass rate of 1 leaves no binomial variance to size from. Epic #1175 requires a null to be
reported with equivalence bounds, and the decision rule had none: an inconclusive interval said
nothing about how large an effect it ruled out.

## Acceptance criteria

1. **Given** a pilot whose pass rate is 0 or 1, **when** `replay_power.py` runs without an
   assumption, **then** it refuses and names `--assumed-pass-rate`.
2. **Given** the same pilot and `--assumed-pass-rate P`, **when** it runs, **then** it sizes the
   design with P in place of the measured rate and prints, and records in its JSON, that P was
   assumed and what the pilot measured.
3. **Given** `--mde E`, **then** it sizes for that minimum detectable effect, the same input as
   `--effect`, still capped at 15%.
4. **Given** a plan's Equivalence margins and a finished run, **when** `scripts/equivalence.py`
   reads them, **then** each metric reads equivalent, not equivalent or inconclusive from the
   task-clustered interval `replay_stats.analyse` reports, and an undefined interval or a margin
   with no interval is inconclusive.
5. **Given** `docs/pre-registration-template.md`, **then** its decision rule states the
   equivalence rule and an Equivalence margins section states each margin, with SM-2's defaults.
6. **Given** the #1144 pilot rows, an assumed pass rate of 0.7 and an MDE of 0.15, **then** the
   power command prints a design.

## Design

### Approach

`replay_power.py` gains `assume_pass_rate`, which replaces the pass rate in the inputs and keeps the
measured one beside a `pass_rate_assumed` flag; `render` prints an assumption line whenever the flag
is set. The refusal at 0 or 1 stays in `check_inputs`, now naming the option. `--mde` is an alias of
`--effect`. A new `scripts/equivalence.py` holds the verdict: interval-inside-bounds on the 95%
interval, margins read from the plan's Equivalence margins section with `experiment_protocol`'s
section and field readers, and a CLI over a results directory.

### Decisions and alternatives

- Default taken: inside-bounds on the existing 95% interval, which is TOST at 0.025 a side, rather
  than a second 90% bootstrap interval, because the summary already produces the 95% interval and
  the stricter test needs no new resampling.
- Default taken: SM-2's margins are 0.85 to 1.1765 on the Cost-of-Pass ratio (the 15% effect and
  its reciprocal) and ±δ on the pass-rate difference, so a plan is filled by default.
- Default taken: a ceiling pilot's measured `tau2_pass` of zero is kept and printed, rather than
  assumed, because the issue names only the pass rate as the assumption.
- Default taken: the Equivalence margins section is not a gated field of `experiment_protocol`,
  so existing plans keep starting; the equivalence command refuses a plan without it.
- Rejected: placing the verdict in `replay_stats.py` or `cost_bench.py`, which other branches edit;
  the summary can import `equivalence.assess`.

### Do not implement

- Wiring the verdict into `cost_bench.py`'s summary; that file belongs to other branches.
- Any replay run or model call.
