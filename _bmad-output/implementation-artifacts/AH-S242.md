## Story

As a harness maintainer, I want a report of how often each kind of recommendation is followed and what following it would have saved, labelled as a soft estimate, so that advisory effects are reported apart from measured figures.

## Context and value

Advisory effects depend on the user following the advice, so PRD §1 reports them apart, as estimates. AD-12 labels such a figure Soft estimate, names its estimator, and never pools it with measured figures. This report gives two figures per recommendation kind: the adherence rate from #792's events, and an if-followed estimate of what following the advice would have saved, priced from recorded sessions and the cache-rebuild causes #748 attributes.

Depends on #792 and #748. Traces to AD-12, PRD §1 and §9 (v0.15.0).

## Acceptance criteria

1. Given adherence events, then the report gives the adherence rate per recommendation kind with a Wilson interval.
2. Given priced session replays, then it gives the if-followed estimate per kind, labelled Soft estimate with the estimator named.
3. Given any figure in the report, then it carries its estimand label, and no soft figure is summed with a measured one.
4. The PRD names the if-followed estimator through `bmad-prd`, since the text of record does not yet.

## Design

### Approach

A read-only report, `citizen usage --by adherence`, gives each recommendation kind two figures. The
adherence rate is followed over judged (followed plus not followed) from the adherence ledger, per kind
and profile fingerprint, with a 95% Wilson interval, labelled measured (unattributed as well when the
row has no fingerprint). The if-followed saving is labelled soft estimate and names its estimator,
carried-context reprice.

For an emission in session S at prompt t: `C` is the context of S's last call at or before prompt t,
`B` that of S's first call, `K = max(0, C - B - H)` with `H = 0`. The horizon is S's calls after
prompt t up to the first compaction rebuild. Actual cost `A` prices the horizon as recorded; the
counterfactual `F` keeps output and uncached input, makes the first horizon call a cold start (reads
nothing, writes `write + max(0, read - K)`), lets a later non-rebuild call read `max(0, read - K)`,
and lets a rebuild write `write - min(K, rewritten)` keeping its tier split. The saving `A - F` is
signed. An unpriced model makes the emission unpriced; an unreadable transcript counts as transcript
missing; neither is priced at $0 (FR-24).

Every number is a `Figure` carrying its label; `total()` refuses mixed labels, the renderer refuses a
bare number, and no grand total spans the two sections. `wilson` moves from `scripts/replay_stats.py`
to `lib/harness_core/intervals.py`, re-imported so every caller keeps working.

### Decisions and alternatives

1. **Counterfactual starting context.** Taken: the fresh session starts from the session's own
   first-call context and the figure reads "at most". Rejected: measuring a handoff from followed
   emissions, which needs #867's live rows and a cross-session join; any fixed number would be invented.
2. **Which emissions are priced.** Taken: only those `adherence.py` answers `not_followed`, keeping one
   definition of following (AD-23); the live estimate is empty until #867 registers observation.
   Rejected: also pricing sessions that ran past the window, a second reading that can disagree with
   the ledger.
3. **Where the PRD names the estimator.** Taken: a new FR-85, Soft-estimate report, in §4.5, planned
   for v0.15.0. Rejected: a consequence under FR-32, which the next recommendation kind would force to
   move.
4. **Evidence standard.** Taken: one sentence under item 10 saying a soft estimate is hypothetical and
   never enters a proof set. Rejected: leaving the standard alone, which leaves AD-12's labels and the
   standard's unconnected.

### Do not implement

- Registering the observation entry point (#867), new recommendation kinds, use in the proof bundle
  (#799) or the Studio (#1062), and calling `adherence.settle`.
- A second transcript parser: session calls come from #748's `rebuilds.py` extraction.
- Registering anything in `benchmarks/`: host sessions are exploratory under the evidence standard.

  the tier split, and an unpriced model counted apart.
- `ReportTests` and `JsonTests` — AC2 and AC3: only `not_followed` emissions are priced, a kind with no
  estimator is unmeasured, every rendered number carries a label, the sections cannot be summed, and
  the JSON follows `usage_json` with unknowns null.

`tests/test_adherence_report.py`:
- `PromptOrdinalTests` — each call's `prompt` counts user prompts as the feed counts a turn, from the
  start of the transcript, sidechains excluded.
- `BreakFieldTests` — `annotate` puts `rewritten` and `cause` on each call, and `analyse` counts the
  same breaks.
- `SessionCallsTests` — a session's transcript is found in any project folder; a missing one is None,
  and an id that is not a plain name is never globbed.
- `ReportCommandTests` — AC1 to AC3 end to end in a temporary `HARNESS_HOME`: the JSON reproduces the
  hand-computed estimate, the text prints both labelled sections, and `--rules`, `--stance` and
  `--rescan` exit 2.

### Completion notes

**2026-09-30, step 5 and the CLI wiring.** #748 merged, and two small fields were added to its call
records so the estimator can read real transcripts through `rebuilds.py` with no second parser:

- `prompt` on every call from `read_calls`, the ordinal of the user prompt it follows. `is_prompt`
  applies the usage feed's turn rule (a user entry that is not a tool result, `isMeta` or
  `isCompactSummary`, sidechains excluded) and counts from the start of the transcript, so an
  ordinal does not shift with the window.
- `rewritten` and `cause` on every call, from a new `annotate()`. `analyse()` now reads its breaks
  from `annotate()`, so the rebuild report and the estimator share one definition of a break;
  `tests/test_rebuilds.py` passes unchanged.

`session_calls()` finds `<session_id>.jsonl` in any project folder, reads the whole transcript and
annotates it; a missing or unreadable transcript is None, which the report counts as transcript
missing, and an id that is not a plain name is never globbed. `citizen usage --by adherence` loads
`adherence` and `usage-feed` by file (AD-11), reads each session once, prints both sections or
`--json`, and refuses `--rules`, `--stance` and `--rescan` with exit 2.
