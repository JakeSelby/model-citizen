## Story

As a developer choosing how `/review` and `/research` run, I want each available as a Workflow script
beside its prose form, with the cost bench saying which is cheaper and whether pass rate moves, so that
any change of default rests on a measured number.

## Context and value

The Workflow tool ships natively in Claude Code. The #540 spike showed that a script's `agent()` calls
bypass the harness's `Agent` hook chain, so a scripted delivery loop must satisfy the delegation rules by
construction rather than by hook. This story measures whether scripted forms of two existing workflows
are worth it. It came from an assessment (§1) and is blocked by #540 and by a clean Bucket D ratio in the
first live replay results (#369).
[Source: https://github.com/JakeSelby/agent-harness/issues/545]

## Acceptance criteria

1. **Given** `primitives/workflows/review.md` and `research.md`, **when** the `scripted` variant is
   added, **then** the prose bodies stay and a script encodes the same DAG: spec-reviewer then reviewer
   in fresh contexts for review; up to three independent gatherers then synthesis for research.
2. **Given** each script, **when** it is reviewed, **then** it satisfies the four delegation rules by
   construction: no command from a summary, no subagent between a verifier and its consumer, no
   same-family shared-context verification, no re-delegation.
3. **Given** a confined role in a script, **when** it is invoked, **then** it runs confined.
   [ASSUMPTION: the issue routes confined roles "through `harness role run` from the script, per
   #540's finding", but #540's record found a script body has no shell access and cannot call
   `harness role run`; the mechanism needs restating before build.]
4. **Given** the delegation stance's `workflow_runner: prose|script`, **when** it selects `script` on
   Claude Code, **then** the script runs; on Codex the variant is reported unsupported and falls back
   to prose.
5. **Given** `scripts/cost_bench.py replay`, **when** it runs a `script` arm against the `prose` arm on
   the same snapshots, **then** results carry normalised cost, turn count, pass rate and the
   cache-prefix figure from #497.
6. **Given** a relaunch, **when** it resumes, **then** it uses cached `agent()` results and the ledger
   shows no duplicate spawns.
7. **Given** the measurement, **when** a default is chosen, **then** a written decision records it with
   the competing explanation it refuted.

## Design

### Approach

Add a `scripted` variant to each workflow primitive, selected by a new `workflow_runner` switch on the
delegation stance, and a `script` arm in the replay bench beside `prose`.

### Decisions and alternatives

- **No default change without the number;** the prose forms stay.
- **Claude Code only;** Codex falls back to prose and says so.
- **Stop condition:** if the measurement programme stops under its recorded stop condition, the issue
  is re-scoped to a qualitative pilot or closed; it does not run unmeasured.

### Do not implement

- A default flip before the replay result.
- Scripts on Codex.
