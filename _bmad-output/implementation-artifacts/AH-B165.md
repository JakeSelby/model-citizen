## Reproduction

On CI, `test_cost_bench_pack.PackVerifyTests.test_a_solution_that_does_not_finish_in_its_container_is_an_error` (PR #1163, Python 3.14) failed when `.git/objects/maintenance.lock` vanished while `open_for_image` walked a workspace `replay_pack.materialize` had built. `test_changelog_release_branch` cleanup failed with `OSError: Directory not empty: '.git'` (PR #1163 on Python 3.9, PR #1210 on Python 3.12). Neither reproduces on demand.

## Root cause

After a commit git may detach automatic maintenance or auto gc, which keeps writing under `.git` while the caller scans or removes the tree. #1154 turned it off in one test helper only. `materialize` runs git with an environment reduced to `HOME`, `PATH`, `TMPDIR` and `LANG`, so no caller setting reaches it, and every other test that creates a repository ran git with maintenance on. [Source: scripts/replay_pack.py#materialize]

## Acceptance criteria

1. **Given** a workspace `materialize` creates, **when** its local config is read with no `GIT_CONFIG_*` variable set, **then** `maintenance.auto` is `false` and `gc.auto` is `0`.
2. **Given** any test module, **when** it runs git in a child that inherits the test process environment, **then** that git sees `maintenance.auto=false` and `gc.auto=0`, whether the module runs alone or in the full suite.
3. **Given** `GIT_CONFIG_*` entries already in the environment, **when** the suite adds its own, **then** the existing entries are kept and none is added twice.

## Design

`materialize` writes both settings into the new repository's config right after `init`, so its own commit and every later git run in the workspace skip maintenance. `tests/isolation.py` appends both settings as `GIT_CONFIG_COUNT`/`GIT_CONFIG_KEY_n`/`GIT_CONFIG_VALUE_n` to the test process environment when imported; discovery imports every module before a test runs, and each module that creates a repository without already importing `isolation` (directly or through `test_harness`) now imports it, so a module run alone is covered too. That replaces #1154's flags in `tests/test_replay_pack.py`. Rejected: tolerating files that disappear mid-walk, which hides the race in one reader and leaves cleanup exposed. `scripts/cost_bench.py` does not change. Children that build an environment without `GIT_*` (the hook matrix fixture) already pass the flags themselves.

## Regression test

`tests/test_git_maintenance.py`: the materialize test fails against the previous `replay_pack.py` and passes after; the suite test checks a repository a test creates; a third checks existing entries are kept.
