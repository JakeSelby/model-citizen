## Story

As a developer, I want a history of every run with its detail, reruns and flaky marks, so that I can see how results relate to past runs.

## Context and value

Every run, launched here or imported, in one filterable history (suite, target, status, cost, duration and date), and a detail page with the per-case table, the log, the artifacts, the exact command and a rerun button. A test that both passed and failed at the same commit is marked flaky, with the runs that show it.

## Acceptance criteria

1. Given two runs of one test at one commit with different outcomes, then the test is marked flaky in both runs and in its own history.
2. Given a rerun, then it uses the same target and parameters and links back to the original.
3. Given 10,000 runs, then the history filters in under 200 ms.
