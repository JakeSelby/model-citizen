## Story

As a developer, I want to change my mode, stances and switches with previews and the CLI's own checks, so that I tune behaviour without hand-editing JSON or breaking a dependency.

## Context and value

Pick a mode, choose a variant for each stance, and switch rules, hooks, skills, workflows and roles on or off, in a draft. Each stance variant shows its operative lines, and each change previews the projected text before and after. The checks `config_set` runs through `load_selection` (switch dependencies and core hooks) run on every change before it is saved.

## Acceptance criteria

1. Given a switch whose dependency is off, when it is turned on, then the Studio shows the refusal `citizen config set` would give and saves nothing.
2. Given a core hook turned off, then the Studio asks for the same explicit acknowledgement as the CLI.
3. Given a variant change, then the preview shows the always-loaded budget before and after.
4. The saved draft config equals what the matching `citizen config set` commands would write, in tests.
