## Story

As a developer, I want to see my effective selection and where each value comes from, so that I know why my agent behaves as it does and which file to change.

## Context and value

Show the resolved selection (the mode, the stance variants, and the switches for rules, hooks, skills, workflows and roles) as `posture.selection()` resolves it, with the layer each value comes from (default, init, mode, user, project or session) and the file that sets it. A developer picks a repository to see its project layer, and sees the always-loaded context budget filled against its cap.

## Acceptance criteria

1. Given a value set in the user layer and overridden in a project layer, when that repository is picked, then the Studio shows the project value, the overridden user value, and both files.
2. Given a session variable such as `HARNESS_STANCE_*` in the Studio's environment, then the Studio labels that value as a session value, not a saved one.
3. The resolved selection equals `citizen selection`'s output for the same inputs, in tests.
4. The budget meter shows the always-loaded total against the cap `citizen lint` enforces, for each runtime.
