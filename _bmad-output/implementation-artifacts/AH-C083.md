## Goal

Record the 2026-09-26 field check behind the Studio (#955 to #959) as a BMad research run, so the UX
specification (#961) and the architecture decisions (#962) cite one decision-first summary instead of
three loose notes. The check asked whether any tool in Model Citizen's class, any coding-agent GUI or any
LLM eval platform ships a local UI that edits an agent's configuration, runs evals against a draft and
compares the result with a baseline.

## Acceptance criteria

1. `_bmad-output/planning-artifacts/research/` holds the run folder, with the three source notes under
   `imports/`, claim digests under `digests/`, and a cited, decision-first `research.md`.
2. The load-bearing claims are spot-checked against primary sources, and anything unconfirmed says so:
   nothing in the class ships the loop; Harbor compares runs of real coding agents; Agenta versions
   coding-agent configurations; `claude plugin eval` measures plugins with and without; no eval UI
   checked reports confidence intervals.
3. The epic map lists this chore under AH-E022, sprint status is current, and `audit` reports no finding.
