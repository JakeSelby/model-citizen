## Story

As a harness maintainer, I want a field experiment that randomises real sessions and analyses them by intention to treat, so that a claim about real work rests on real sessions rather than a fixed task set.

## Context and value

Replays measure the harness on a fixed task set. A claim about real work needs real sessions, randomised. PRD §9 plans intention-to-treat analysis for v0.17.0; this builds the experiment around it: assignment, pre-registered outcomes, a sample-ratio check, a novelty split and CUPED variance reduction.

Depends on #789, #792, #794 and #128. Traces to PRD §9 (v0.17.0).

## Acceptance criteria

1. Given an opted-in user, when a session starts, then its arm is assigned at random and recorded before the first turn.
2. Given the pre-registration, then its outcomes and covariates are fixed before the first assignment.
3. Given the assignments, then a sample-ratio check runs before any effect is read, and a mismatch stops the analysis.
4. Given the outcomes, then intention-to-treat effects are published with intervals, early and late sessions are reported separately, and CUPED uses only pre-registered covariates.
5. The PRD gains the requirement through `bmad-prd`, since the text of record names only intention to treat.
