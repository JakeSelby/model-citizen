## Story

As a developer, I want to run the free local suites from the Studio, down to one test, so that checking a change costs a click and nothing else.

## Context and value

The suites that spend nothing run from the Studio: the unit tests (all of them, one module, one class or one test, listed by discovery), `citizen lint`, the static context figure (`cost_bench.py static --check`), the detector corpus (`detector_corpus.py --json`) and lifecycle acceptance. A developer picks one, watches its log stream, stops it, and sees each test or check with its result and failure detail.

## Acceptance criteria

1. Given one unit test picked from the discovered list, then only that test runs, and its result and traceback show.
2. Given the full suite, then progress shows per test as it runs, and the log streams without slowing the page.
3. Given a lint run, then each finding links to its file and line in the library.
4. The command chip on each run shows the exact command, and running it by hand gives the same result.
