## Story

As a solo or small-team agentic developer, I want Baseline to record where my harness starts from what I already have, so that later periods have something to compare against.

## Context and value

Plan step 7. Baseline replaces Setup: it reads the current config and plugins and records a baseline period that AH-S369 and Evals compare against.

## Acceptance criteria

1. **Given** a current config and plugins, **when** Baseline runs, **then** it records a baseline period with their state.
2. **Given** the old Setup route, **when** opened, **then** it lands on Baseline.
3. **Given** a recorded baseline, **when** Evals renders, **then** it is a period it can compare against.
4. **Given** the route, **when** its API tests run, **then** they cover shape, auth and errors; node tests and an e2e flow cover the page.

## Design

### Approach

- A Baseline route and page; the period recorded under the Studio state directory.

### Decisions and alternatives

- **Start from what you have:** no preset to pick. Rejected: beginner presets (out of scope).

### Do not implement

- Beginner presets; config changes.
