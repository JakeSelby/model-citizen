- The breakdown follows `bmad-create-epics-and-stories`: epics by user value (open, tune, run, judge,
  adopt), each standalone and building only on earlier ones, and stories sized for one pull request, with
  Given, when, then criteria, no forward dependency, and every new FR covered. `epics.md` gained sections
  rather than being regenerated from the skill's template, since this repository keeps a living epic map.

  prior decision: AD-21 admits third-party code only as vendored wheels, so the bundled UI waits on
  AH-T036's amendment.

  §4.16 after §4.14 and starts at FR-75, so neither renumbers the other; whichever merges second keeps
  both neighbouring insertions in the PRD and `epics.md`.
- Another session took #993 during the filing, so AH-E025's children skip it.
