## Story

As a solo or small-team agentic developer, I want a Skills page showing which skills were loaded versus invoked, so that I can drop skills that cost context and never run.

## Context and value

Plan step 6. Built on the transcript index (AH-S376): Skill tool calls give the invoked list; the session's skill listing gives the loaded list. It sits in the Harness group with the two-tab frame.

## Acceptance criteria

1. **Given** indexed sessions, **when** the Skills page opens, **then** each skill shows how many sessions loaded it and how many invoked it, per period.
2. **Given** a skill loaded but never invoked in the window, **when** the page renders, **then** it is marked so.
3. **Given** the page's route, **when** its API test runs, **then** it asserts period-stamped rows, the response shape, auth enforcement and error cases.
4. **Given** the page, **when** design-judge scores it against its round-3 artboard, **then** the score is at least 7, and node tests and an e2e flow cover it.

## Design

### Approach

- A Skills route over the index; Efficacy rows per period.

### Decisions and alternatives

- **Read at page load from existing logs:** no hook-side recording (epic scope). Rejected: new recording for this page.

### Do not implement

- Changes to other Harness pages; new hook-side logging.
