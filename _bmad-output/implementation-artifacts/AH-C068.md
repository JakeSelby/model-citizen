## Goal

Give Jev ledger rows a cost, so each decision point's cost figure (AH-E003 exit criterion 1) exists.
The rows are unpriced because no price was published when #139 landed. TypeSafe now lists one,
reported as $0.042 per million input tokens with output free.

## Acceptance criteria

1. **Given** a Jev row with token usage, **when** it is costed, **then** it gets a cost from the price
   table's Jev entry.
2. **Given** the entry, **when** it is read, **then** it names its source and the date the price was
   checked.
3. **Given** a missing or unconfirmed price, **when** a row is costed, **then** it is named as unpriced,
   never zero.

## Tasks

- [ ] Confirm the price on TypeSafe's own pricing page (AC: 2)
- [ ] Add the Jev entry to `policy/prices.json` (AC: 1, 2)
- [ ] Test a priced row and an unpriced one (AC: 1, 3)

## Dev notes

- The price table is `policy/prices.json`, read through `bin/harness`; the unpriced-row rule lives
  in [Source: lib/harness_core/decisions/ledger.py].
- The reported price comes from TypeSafe's launch post and OpenRouter's listing. Neither is the
  vendor's pricing page, so confirm it before adding.
- A price is not a figure that measures the provider's model, so FR-49's publication limit does not
  apply to it.
- This chore changes `policy/`, so its PR updates `product.json` or carries a `Landing copy:` line.
