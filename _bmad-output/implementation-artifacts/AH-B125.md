# AH-B125 — qualification_provision runs its git calls under an inherited GIT_DIR, so they can act on another repository

## Reproduction

Create a source repository with two commits and a second clone to act as a decoy. Export the
decoy's absolute `.git` path as `GIT_DIR`, then ask `qualification_provision.clone()` to freeze the
source repository at its older commit. The clone's `git -C` calls inherit `GIT_DIR`, so Git may
operate on the decoy instead of the new round clone. The provision record can consequently name a
source commit that the round clone never checked out, while the operator's decoy repository is
mutated.

## Root cause

`scripts/qualification_provision.py::run` passes the complete caller environment to every child.
Repository-local Git variables such as `GIT_DIR`, `GIT_WORK_TREE`, and `GIT_COMMON_DIR` override
the repository selected by `git -C`; `-C` alone is therefore not an isolation boundary.

## Acceptance criteria

1. **Given** `GIT_DIR` points at a decoy repository, **when** a round clone is frozen at a named
   source commit, **then** the round clone reaches that commit and the decoy HEAD remains unchanged.
2. **Given** repository-local Git variables and an unrelated intended environment variable, **when**
   `run()` launches a child, **then** the Git variables are absent and the intended variable remains.
3. **Given** Git reports additional repository-local variable names, **when** the isolated child
   environment is built, **then** those names are scrubbed in addition to the known fallback set.
4. **Given** the completed fix, **when** the Python 3.9 checks, generation check, and repository Gate
   run, **then** all pass.

## Design

At module load, ask Git for `rev-parse --local-env-vars` and union that result with the established
fallback set used by the merge-driver tests. Add an `isolated_environment()` helper that copies
`os.environ` without those names. Pass that environment to every subprocess launched by `run()`;
this protects clone, checkout, HEAD, cleanliness, and optional installer calls while preserving
PATH, credentials, and explicit qualification variables that are not repository selectors.

Clearing only the three variables named in the report was rejected because Git exposes additional
repository-local selectors. Clearing the whole environment was rejected because provisioning must
retain the operator's intended executable path and installer environment.

## Regression test

`tests/test_qualification_provision_git_env.py` builds a two-commit source and a decoy clone, exports
the decoy's `GIT_DIR`, and proves provisioning checks out the requested source commit without moving
the decoy HEAD. A child-process probe proves repository selectors are removed while an unrelated
sentinel variable survives.
