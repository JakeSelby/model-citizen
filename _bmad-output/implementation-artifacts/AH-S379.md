## Story

As a solo or small-team agentic developer, I want a Changes inbox listing drafts and past rollbacks, so that every change waiting or undone is in one place.

## Context and value

Plan step 6. Adds routes over `drafts.list` (new; `drafts.py:228,320`) and rollback history (`rollback.py:65`), and reuses review, test, apply and recover as they are. Settings saves from S3 land here.

## Acceptance criteria

1. **Given** drafts, **when** the draft-list route is requested, **then** it returns each draft with its source page and state.
2. **Given** rollbacks, **when** the rollback-history route is requested, **then** it returns past rollbacks newest first.
3. **Given** a draft, **when** it goes list, test, apply, roll back, **then** each step works through the existing paths and shows in Changes.
4. **Given** the new routes, **when** their API tests run, **then** they cover shape, auth and errors; node tests and an e2e flow cover the inbox.

## Design

### Approach

- `drafts.list` added beside the existing draft functions; two routes; the inbox page.

### Decisions and alternatives

- **Reuse review, test, apply and recover:** one governed path. Rejected: new apply logic in the inbox.

### Do not implement

- Changes to apply or recover semantics.
