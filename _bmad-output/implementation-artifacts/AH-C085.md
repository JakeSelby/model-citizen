## Goal

Cuts the root `AGENTS.md`, which every session that adds this repository loads, down to what another folder's session
needs, and moves the repository-internal instructions into `.claude/rules/working-here.md`, which Claude Code loads
only in sessions started here. Nothing that runs changes.

## Acceptance criteria

1. The root file keeps its title paragraph, a new `## For other repositories` section, `## Gate` and the one-file
   section, byte for byte.
2. Every other section moves byte for byte and in order into `.claude/rules/working-here.md`, scoped with
   `paths: ["**/*"]` written as a YAML list, unless a test, script, workflow or doc reads it.
3. A mechanical check shows every original line in one of the two files, in order, with only the new section, the
   front matter and the heading added.
4. The gate is green.
