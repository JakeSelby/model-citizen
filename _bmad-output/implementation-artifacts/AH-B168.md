## Reproduction

Run any Claude Code 2.1 session with the usage feed on and a cost variant whose `turn_feed` is not
`off`. After most main-session turns the next prompt carries
`usage-feed: unknown finished, spend unknown, no transcript found for agent a…`. Replayed over this
maintainer's last seven days of feed journals (counts only), 459 of 776 finished-subagent stops,
59.1%, read `spend unknown`; over the last day, 111 of 190.

## Root cause

Not the transcript lookup. Every stop that had a `SubagentStart` before it resolved its transcript
under `<project>/<session>/subagents/agent-<id>.jsonl`, the layout `agent_transcript` already names.
Every unknown stop had no start, no `agent_type`, and no transcript anywhere on disk, and 105 of
the last day's 110 fired within five seconds of a main-session `Stop`. They are Claude Code's own
end-of-turn agent, which fires `SubagentStop` and nothing else, and the feed counted and reported
each one as a finished subagent. The share rose after 09-28 with the mix of turns to spawned
agents, not with a layout change. [Source: policy/hooks/usage-feed.py#on_subagent_event]

## Acceptance criteria

1. **Given** a `SubagentStop` with no agent type and no readable transcript, **when** it is
   journalled, **then** the record carries `internal: true`.
2. **Given** an `internal` stop with no journalled start, **when** the reader ingests it, **then**
   no line names it and the session's subagent count and unknown count do not include it.
3. **Given** an untyped stop whose start was journalled, or a typed stop with no transcript,
   **when** it is reported, **then** it still reads `spend unknown` naming the agent.
4. **Given** a spawned agent in the current `subagents/agent-<id>.jsonl` layout, **when** it
   finishes, **then** its line carries the figure summed from that transcript.
5. **Given** this maintainer's last day of feed journals, **when** the lookup and the skip are
   replayed, **then** the unknown share is under 5%.

## Design

The stop marks the record `internal` when the payload has no `agent_type` and `readable(path)`
fails; it still journals it, so nothing about the start/stop pairing changes. `internal(state,
record)` adds the third fact, that no start for the id is in `state["running"]`, and `ingest`
skips such a stop before counting it, while `to_settle` tracks starts in the same bytes and spends
no sum budget on it. Rejected: walking the session tree or other directories for the transcript,
since none exists anywhere; and skipping on a missing type alone, which would hide a spawned agent
whose transcript is lost. Must not change: the lookup paths, the old `subagents/workflows/wf_*`
layout, or any line for a started or typed agent.

## Regression test

`tests/test_usage_feed_internal.py` replays the synthetic current-layout fixture in
`tests/fixtures/usage-feed/current-layout/` through the hook; against the unfixed hook four of its
seven tests fail, and all pass after.
