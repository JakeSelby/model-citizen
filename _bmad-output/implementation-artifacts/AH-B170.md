# AH-B170 — fix(security): grade-bash grades a read of the harness config as a write

## Reproduction

With the governance binding live, two commands that write nothing to the harness configuration are refused as level-1 changes to it:
- an inline Python program that only reads the file (`json.load(open(path))`, no mode, no write call);
- `gh issue create --body "..."` whose quoted body names the path.

Observed twice on 2026-10-05.

## Root cause

The governance binding treats any mention of the configuration path in a command line as a change to it. `bash-grader.py` searches the whole line for the path, so it can't tell a mention inside an inert program or inside quoted argument text from a write.

## Acceptance criteria

1. **Given** an inline program that opens the path with no mode, `'r'` or `'rb'`, and makes no write call, **when** it is graded, **then** it grades as a read.
2. **Given** a `gh` issue or PR command whose quoted text value names the path, **when** it is graded, **then** the mention is not a write.
3. **Given** any existing write route (open with `'w'`, `'a'`, `'x'` or `'r+'`; `write_text`; `json.dump`; a redirect; `cp` or `mv` onto the path), **when** it is graded, **then** it stays gated.

## Design

`data_mentions_only` exempts a line from the configuration-mention search only when every mention is quoted and is either in an inline program that only reads, or in a gh text value, including a quoted here-document that `cat` or gh reads in. A line where a command runs text as a shell, a redirect targets the path, or a loop header names it is never exempt. `_program_writes` gains a `modes` flag so `open(p, 'rb')` reads.

Two alternatives were rejected. Dropping the mention search would lose real writes. Allowlisting gh would let a gh command whose shell expansion writes slip through.

The approvals-store check is unchanged. `git commit -m` naming the path stays gated, because an existing test requires it.

## Regression test

`tests/test_governance_read_mentions.py` covers the two false positives, every write route, and near misses that must stay gated: piped to `sh`, an assignment prefix, an unquoted path, an unquoted here-document, and `cat 1<>`.
