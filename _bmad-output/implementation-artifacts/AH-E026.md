## Goal

A developer who has just installed Model Citizen reaches a tuned, measured harness through a guided
first run, and their agents run the same loop headless from the CLI. The Studio meets WCAG 2.2 AA at
every width down to a phone, is checked end to end and against performance budgets in CI, is
documented and in the product copy, and is qualified in every release.

Completion is observable: a fresh install reaches an applied draft with green doctor checks through
the Studio; a mutating route with no CLI equivalent fails a test; the six flows pass end to end in CI;
and the release preflight fails on a stale bundle.
