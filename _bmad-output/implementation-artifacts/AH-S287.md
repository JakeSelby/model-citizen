## Story

As a developer, I want to browse every module with its manifest, projection and context cost, so that I know what my harness loads and what it costs.

## Context and value

Browse every module the harness can load (rules, stances and their variants, skills, hooks, roles, workflows, modes and output styles) from the core and from each primitive root. Each module shows its manifest fields from `primitives/manifests.json`, its on or off state, rendered and source views, the files it projects to for each runtime, and its static context cost.

## Acceptance criteria

1. Given a module in a developer's primitive root with the same name as a core module, then both are listed with their roots and the collision is flagged.
2. Given a module switched off, then it shows as off, with the layer that switched it off.
3. Given a rule, then its page shows the files it projects to for Claude Code and for Codex, and its token cost from the static context figure.
4. Given a library of 500 modules, then search and the filters by kind, root, state and cost answer in under 100 ms.
