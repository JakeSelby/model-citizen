## Goal

Correct canonical plugin procedures identified by the directory review, then regenerate all
native and directory projections from those sources.

## Acceptance criteria

1. Build fallbacks honor builder prerequisites; topic-only plans do not invent issue trailers.
2. Both fresh reviewers receive the same frozen diff artifact and commit identities.
3. Standalone verification, transcript and output-style guidance does not require resident rules.
4. Visual review includes evidence for hard gates that images cannot prove.
5. Migration archives precede removal; upstream and worktree cleanup preserve local work.
6. Workflow status uses exact run IDs, journal-based agent status and explicit terminal evidence.
7. Generated projections, plugin validation and the full repository Gate pass.

## Design

Edit canonical workflow, role, skill and presentation sources, then run `harness generate` and
`sync_directory_plugin.py`. The workflow reader joins `agentId` and journal keys; inactivity
never establishes completion. An explicit runtime completion notification may be supplied with
`--terminal-status` for an exact `--run`; without it the overall run remains unknown.

- [x] Correct status reader and skill-directory invocation, with executable regressions. (AC 6)
- [ ] Complete generated/plugin checks, full Gate and independent review. (AC 7)
