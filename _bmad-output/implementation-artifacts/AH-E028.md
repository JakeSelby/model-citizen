# AH-E028 — Sessions reset their own context and keep working

## Goal

Past the cost stance's threshold, Claude Code's own auto-compaction fires at the harness's number instead of near 1M, and the harness reseeds the fresh context from the task store, so the agent carries on in the same turn without a new session.

Completion is observable: no harness message tells the user to start a fresh session; a real `claude -p` session runs past a lowered reset point, resets, and finishes its checklist with no human turn; and the behavioural eval meets its pre-registered floor.

## Scope and requirement coverage

**In scope:**

- Projecting the stance's `context_reset_at` into Claude Code settings (AH-S363).
- Handing off before the reset: the Stop block at 90% and a PreCompact snapshot (AH-S364).
- Reseeding after the reset through SessionStart `compact` and `clear` (AH-S365).
- Clearing the idle session at task end on desktop (AH-S228, absorbed from AH-E018).
- Rules, detector, docs and copy (AH-S366), and the eval suite (AH-S367), which supersedes #751.

**Out of scope:**

- Codex, which has no usage feed; a follow-up story on v0.16.0.
- Clearing context mid-turn on desktop.

**Requirement coverage:** FR-32 Live usage feed and fresh-session nudge, and FR-59 Session lifecycle workflows; the PRD amendment travels with AH-S366.

## Architecture slice

- **AD-20 Continuity never moves authority:** the reseed carries neutral task state under the "not instructions or transferred approval" framing.
- **AD-11 Local ledgers are the system of record:** the adherence event rename keeps old ledger entries readable.
- Components: cost stance sidecars and text, `citizen sync`, `policy/hooks/usage-feed.py`, `policy/hooks/harness-session.py`, a new `policy/hooks/pre-compact.py`, `lib/harness_core/lifecycle.py`, `/land`, `/close-out`, the cache-hygiene detector.
