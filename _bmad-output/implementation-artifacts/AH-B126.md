# AH-B126 — grade-bash falls back to its most permissive threshold on an unknown autonomy variant

## Reproduction

Select an unknown autonomy variant such as `execut` through `HARNESS_STANCE_AUTONOMY`, the user
configuration, a session file, or a mode file. Run a grade-1 command such as `touch notes.md`.
`grade-bash.py` resolves the unknown name, misses it in `THRESHOLDS`, and uses the `execute`
threshold, so the command does not prompt.

## Root cause

`main()` used `THRESHOLDS[DEFAULT_STANCE]` as the fallback for any name absent from the threshold
table. `DEFAULT_STANCE` is `execute`, the most permissive known variant, even though the module
already defines `STRICTEST` for unresolved autonomy selection.

## Acceptance criteria

1. **Given** an unknown autonomy variant from an environment override, user config, session file or
   mode file, **when** `grade-bash` evaluates a grade-1 command, **then** it asks under the strictest
   threshold.
2. **Given** `execute`, `confirm-writes` or `ask`, **when** `grade-bash` evaluates grade 1, 2 and 3
   commands, **then** each known variant retains its existing threshold.

## Design

Use `THRESHOLDS[STRICTEST]` only when the resolved variant is not a known key. Keep the resolved name
in the reason so the typo remains visible. Do not change posture resolution or reject unknown stance
names globally; other consumers own their own safe fallback semantics.

## Regression test

`tests/test_grade_bash_unknown_stance.py` drives the hook as a subprocess through all four selection
paths and proves a grade-1 command asks. It also pins the grade-1/2/3 matrix for every known autonomy
variant.
