## Story

As a prospective user who already runs a skill library, I want the harness's public copy to say it is
the layer under that library, so that I understand what it adds that a skill library cannot claim.

## Context and value

Epic #552's outcome ends with "the copy says what the harness is under a skill library" [Source: #552]. The direction
was agreed on 2026-09-22 (issue text): lead with what a skill library cannot claim (enforcement, cost
posture, model routing, projection to every runtime); every unit is a switch and a mode is a named set of
them; superpowers installs on top and loses nothing. The issue carries the direction, not the text: a
separate copy session produces the draft, and the owner approves it before anything is applied.
[Source: https://github.com/JakeSelby/agent-harness/issues/561]

## Acceptance criteria

1. **Given** a copy session, **when** it runs, **then** it produces the hero, the description, the GitHub
   description and one new capability group as a draft, approved before apply.
2. **Given** the applied copy, **when** `scripts/sync_about.py --check` runs, **then** it names only the
   description and topics; **and** `.github/scripts/check_landing_copy.py` passes.
3. **Given** `product.json`, **when** the README groups regenerate, **then** there is no drift, and the
   site smoke test passes at the release pin.
4. **Given** the copy, **when** it is checked, **then** no figure appears that is not in
   `benchmarks/history.jsonl`.
5. **Given** the topics, **when** they are applied, **then** they include `superpowers` and
   `agent-skills`.

## Design

### Approach

Draft in a separate copy session; apply the approved text through `product.json`, the README, the GitHub
description and the site pin. `product.json` is the one source of landing, README and About copy.

### Decisions and alternatives

- **Direction, not text, lives in the issue;** the words are drafted and approved separately.
- **Only the figure line waits on #560;** the copy session can run at once.
- **Figures only from `benchmarks/history.jsonl`.** That file does not exist on `main`, so today no figure
  can appear. The only uncontaminated live result (1.052 of bare) failed the publish bar; no saving
  may be stated.

### Do not implement

- Applying any copy before the draft is approved.
- A cost or saving line before a live result passes the publish bar.
