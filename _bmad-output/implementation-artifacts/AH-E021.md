# AH-E021 — Run a burndown bot for owner-labelled bugs and scanned vulnerabilities

This work item was authored as part of the repository's committed BMad planning system.

## Goal

Owner-labelled bugs get fixed without a live session, and scanned vulnerabilities reach a private draft
advisory before anyone else sees them. A Claude lane (GitHub Actions running claude-code-action on the
subscription token) and a Codex lane (`@codex`, on the ChatGPT plan) share the bugs; each fix is one pull
request to `main`, worked through CodeRabbit to merge under the bot's own GitHub App. Every attempt is
randomised and recorded, so the bot's work is also a stream of the v0.17.0 field experiment
([#803](https://github.com/JakeSelby/model-citizen/issues/803)).

Completion is observable: an owner-labelled test bug is fixed and merged by each lane with no live
session, a seeded finding produces one draft advisory and no public trace, and the harvest command
rebuilds an attempt table in which every attempt appears as assigned.

## Scope and requirement coverage

**In scope:**

- The bot's identity and trust boundary: its own GitHub App, an owner-label gate, and a two-job split
  between the agent and the writer (AH-S274).
- A hard budget: turns per run, attempts per day and week, an off-hours window, a pause switch and a
  clean stop on a limit error (AH-S275).
- Two bug lanes, Claude (AH-S277) and Codex (AH-S279), after a spike on what can trigger `@codex`
  (AH-SP016).
- Review through to merge under a merge switch (AH-S278).
- A private vulnerability lane (AH-S280).
- The study record and benchmark hygiene (AH-S276, AH-S273).

**Out of scope:**

- Pull requests to `stable` and automated patch releases: `stable` only fast-forwards to release tags,
  and installs update with `merge --ff-only` [Source: scripts/install.sh].
- The study's analysis, which stays with #803 (v0.17.0).
- gh-aw and codex-action, whose Claude and Codex paths take API keys only; Copilot's coding agent and
  other hosted agents; Claude Code routines; CodeRabbit Autofix, which would add a third author to the
  study's outcomes.

**Requirement coverage,** against the 2026-09-23 PRD's §4.15 Unattended maintenance:

- **FR-71 Unattended bug-fix lanes:** AH-SP016, AH-S274, AH-S275, AH-S277, AH-S279.
- **FR-72 Review through to merge:** AH-S278.
- **FR-73 Private vulnerability lane:** AH-S280.
- **FR-74 Randomised real-work stream:** AH-S273, AH-S276, AH-S277.

## Architecture slice

- **A new invariant:** the agent job holds a read-only token and no App token; only a job with no agent
  holds the App token and writes. AH-S274's delivery amends the spine through `bmad-architecture`.
- **AD-9 Checks bind subagents; decisions flow up:** the bot inherits every check a session is bound by,
  and the owner's decisions stay the owner's.
- **AD-12 Measurement invariants:** the arms differ in the user-level install alone.
- **AD-21 Dependencies:** claude-code-action, create-github-app-token and zizmor each pass licensing
  review before use.

## Sequencing

- AH-SP016 and AH-S273 have no dependencies and go first; AH-S273 merges before the bot's first pull
  request.
- AH-S274 and AH-S275 follow; every lane depends on both. AH-S276's pre-registration merges before the
  first assignment.
- AH-S277 needs AH-S273 to AH-S276. AH-S278 needs AH-S277. AH-S279 needs AH-SP016 and AH-S278.
  AH-S280 needs AH-S274 and AH-S275, and can run in parallel with the lanes.
- **Owner steps** gate the build: registering the App, storing its secrets and the Claude token, and
  connecting Codex are never run by an agent.
- **Open defaults** pending the owner's confirmation: Codex's share (AH-S279), the merge switch's
  starting value (AH-S278), and who applies a vuln fix (AH-S280).
- **Risk:** too few eligible bugs to power the study. Bugs close in a median of 0 days, so AH-S276's
  pre-registration sets a minimum sample and a stop date, and the owner labels bugs for the bot as they
  are filed.
- **Milestone:** v0.15.0.

## Exit criteria

- [ ] AH-SP016 records a result for all four cells, and AH-S279's trigger path follows it.
- [ ] One owner-labelled test bug per Claude arm and one in the Codex lane is fixed, reviewed and merged
  or labelled ready to merge, with no live session.
- [ ] A label from anyone but the owner, a `.github/` patch and a set pause switch each produce no agent
  action.
- [ ] A seeded finding produces one draft advisory and no public trace; a repeat produces none.
- [ ] The harvest rebuilds the attempt table with every attempt as assigned.
- [ ] `cost_bench.py` without `--tag` exits non-zero, and a bot-authored mined task fails validation.
