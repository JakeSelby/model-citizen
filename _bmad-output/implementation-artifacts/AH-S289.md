## Story

As a developer, I want the Studio to reflect changes from the CLI, agents and editors within seconds, so that it never shows me a stale harness.

## Context and value

The Studio watches the configuration, the primitive roots, the ledgers and the run store, and pushes a change event to open pages over server-sent events, so a developer never reloads. The watcher polls modification times with the standard library, with no file-system watcher dependency, and a page refetches only the data a change touches.

## Acceptance criteria

1. Given the Studio open on the selection, when `citizen config set` changes a stance, then the page shows the new value within two seconds, without a reload.
2. Given a change to one module, then only the views showing that module refetch.
3. Given 20 open event streams and a library of 500 modules, then the watcher uses under 2% of one core.
