## Story

As a maintainer of the hook replay matrix, I want its Stop call to be the input Claude Code
actually hands a Stop hook, so that the matrix replays every hook event against a native payload
rather than an envelope we derived ourselves.

## Context and value

Split from #511 so its code could land. Its Stop call was a synthetic envelope derived from a
recorded `result` record, because no kept artifact held a Stop hook's input. The micro campaign's
pre-registration expected its `--raw` streams to yield one, but stream-json reports a hook's start
and response only, never its stdin; the observer ledger keeps identifiers only, by design. A
native capture also shows the fields Claude Code 2.1.280 now sends a Stop hook (`prompt_id`,
`effort`, `last_assistant_message`, `background_tasks`, `session_crons`), which the synthetic
envelope lacked.

## Acceptance criteria

1. **Given** the hook-calls corpus, **when** its Stop call is read, **then** its provenance names a
   native recording: kind `recorded-native-stop`, the run, the arm image, the Claude Code version
   and the sha256 of the raw capture.
2. **Given** the recorded payload, **when** it is committed, **then** it carries no home path, no
   real session or prompt id and no message content: identifiers are fixed synthetic values and
   free text is a placeholder, while every key the CLI sent is kept and listed in `native_keys`.
3. **Given** the replaced fixture, **when** `hook_matrix.py --write` regenerates the matrix,
   **then** the committed matrix matches and `tests/test_hook_matrix.py` passes.

## Design

### Approach

One short headless turn in a bare arm container (no harness hooks or rules) ran with a Stop hook
passed through `--settings` that writes its stdin to a mounted folder and prints nothing. The
capture was sanitized by key: `session_id`, `prompt_id`, `transcript_path` and `cwd` map to the
corpus's fixed synthetic values, enum values (`permission_mode`, `effort.level`) and booleans are
kept, and any other string becomes `<placeholder>`. The result replaces the synthetic fixture
under the same file name, so the matrix keeps its call name.

### Decisions and alternatives

- A bare arm image, not the harness arm: the payload is the runtime's, and a bare profile has no
  other Stop hook that could alter the session. The micro campaign's exact bare image had been
  pruned, so the newest bare arm image with the same Claude Code version (2.1.280) was used.
- No benchmark-runner change: the runner installs hooks through managed settings it owns, so the
  one-off capture used `--settings` on a direct container run instead.
- The provenance test skips the source-excerpt check for the Stop call, since there is no
  excerpt; a dedicated test asserts the recorded source instead.

### Do not implement

- No change to the benchmark runner or its observer, and no persistent hook-stdin capture.
- No change to the other recorded calls or to the shared source excerpt.
