## Story

As a solo or small-team agentic developer, I want Roles and Workflows pages showing spawns, tier, effort and cost, so that I can see what delegation costs and where tiering rewrote a spawn.

## Context and value

Plan step 4. Reads usage subagent and worker rows (`usage-log.py:770-800, 1784-1808`) for spawns, tier, effort, cost and the `workflow` field; tier rewrites come from the `tier-agent-spawns` decision point. Target artboards `Roles.dc.html`, `Workflows.dc.html` and their Settings artboards.

## Acceptance criteria

1. **Given** usage subagent and worker rows, **when** the Roles page opens, **then** each role shows spawns, tier, effort and cost per period.
2. **Given** rows with a `workflow` field, **when** the Workflows page opens, **then** each workflow shows its runs and cost per period.
3. **Given** `tier-agent-spawns` decisions, **when** the Roles page renders, **then** tier rewrites show against the role.
4. **Given** the page's route, **when** its API test runs, **then** it asserts period-stamped rows, the response shape, auth enforcement and error cases.
5. **Given** the page, **when** design-judge scores it against its round-3 artboard, **then** the score is at least 7, and node tests and an e2e flow cover it.

## Design

### Approach

- Two pages over the same usage rows; tier rewrites joined from decisions.

### Decisions and alternatives

- **Read at page load from existing logs:** no hook-side recording (epic scope). Rejected: new recording for this page.

### Do not implement

- Changes to other Harness pages; new hook-side logging.
