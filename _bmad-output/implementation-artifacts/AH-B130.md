## Reproduction

The installation case stops as unverified before asking Codex for its projected role list.

## Root cause

The shared native-only guard treats role discovery like Claude-only subagent transcript records,
although sync projects agent definitions into Codex's home.

## Acceptance criteria

1. Installation asks Codex to list `agent_type` values for `spawn_agent` after identity and skill checks.
2. Missing harness roles fail the case; a complete list including additional native roles passes.
3. Claude Code keeps its Agent/subagent_type prompt; other native-only record gaps remain unchanged.
4. Capabilities explain role discovery separately from execution qualification and native records.

## Design

Remove the installation-only early gap. Select a role-list prompt matching the client's tool and
make the discovery turn tool-free. Reuse the existing expected harness role set and missing-role
failure. Preserve the operator-confirmed-home requirement in the probe layer.

## Regression test

Stubbed homes exercise both runtime prompts, complete role lists with native extras, and a missing
Codex role. Existing runtime-gap tests protect other Claude-only record checks.
