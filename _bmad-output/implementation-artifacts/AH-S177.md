## Story

As a maintainer of the cost benchmark, I want real model responses recorded under a normalised-request
hash and replayed offline in CI, failing loud on a miss, so that the runner and its fixtures are
regression-tested without spend and a changed prompt can never score against a stale response.

## Context and value

Item B9 of the 2026-09-22 enterprise-review intake. The intake found the premise true:
`scripts/cost_bench.py` calls the real CLI, keys nothing by request hash, and #369 had no committed
result. It ranked the item lower than proposed: a replay tier does not yield the saving figure, since
both arms would score stale responses, and what it buys is regression coverage of the runner and its
fixtures, which `verify_tasks` already gives without a model. It slotted the item after #369 has one
published row, as a fail-loud fixture cache for the runner's own tests. The issue is open; its
milestone field says v0.16.0, where #528 had placed it in v0.15.0.
[Source: https://github.com/JakeSelby/agent-harness/issues/525]
[Source: _bmad-output/planning-artifacts/roadmap-intake-enterprise-review-2026-09-22.md]

## Acceptance criteria

1. **Given** a live run, **when** `cost_bench.py` records it, **then** each response is stored under
   `benchmarks/recordings/`, keyed by a hash of the normalised request.
2. **Given** `--replay-recorded`, **when** a request's hash has a recording, **then** the recorded
   response is replayed offline.
3. **Given** `--replay-recorded`, **when** a request's hash has no recording, **then** the run fails
   with an error that names the differing request, never a silent pass.
4. **Given** CI, **when** it runs, **then** the recorded tier runs, and the live tier stays hand-run per
   `docs/benchmarks.md`.
5. **Given** #369, **when** it has no published row, **then** this work does not start.

## Design

### Approach

Not recorded in the issue or pull request. At `origin/main`, `scripts/cost_bench.py` has a `replay`
command that runs pinned tasks headlessly against a bare profile and against the harness, and there is
no `benchmarks/recordings/` directory or `--replay-recorded` flag.
[Source: scripts/cost_bench.py]

### Decisions and alternatives

- **Beneath the live run, not instead of it:** the issue says the tier does not replace the live run
  or produce the saving figure.
- **Ranked below the review's proposal,** for the reason above.
[Source: _bmad-output/planning-artifacts/roadmap-intake-enterprise-review-2026-09-22.md]

### Do not implement

- Any saving figure from recorded responses. [Source:
  https://github.com/JakeSelby/agent-harness/issues/525]
- Automating the live tier in CI. [Source: https://github.com/JakeSelby/agent-harness/issues/525]
