## Goal

Every result sits beside its baseline and its history, with honest statistics: paired comparisons
with the paired, task-clustered intervals, a verdict for a draft against its base, trends across
versions beside the proof set, rule health, spend from the local ledger, and stance proposals the
developer tries in a draft. Evidence proposes, and the developer applies.

Completion is observable: an interval that spans no effect reads as inconclusive whatever the point
estimate; a tested draft shows a verdict that goes stale when the draft changes; the rule table
equals `citizen usage --rules`; and trying a proposal changes nothing live.
