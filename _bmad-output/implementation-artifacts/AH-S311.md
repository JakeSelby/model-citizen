## Story

As a developer, I want my spend by day, model, role and repository from the local ledger, so that I manage cost without an external backend.

## Context and value

Spend by day, model, role, repository and session from the usage ledger through `citizen usage --json` (#909), with subagent spend and cache-rebuild attribution by cause (#748), and every figure labelled as a list-price equivalent. It reads the local ledger only; OTLP export stays as it is.

## Acceptance criteria

1. Given the ledger, then the totals equal `citizen usage --json` for the same window.
2. Given any figure, then it carries the list-price label and the pricing date.
3. Given a ledger holding a year of sessions, then the page loads in under a second.
