## Goal

Qualify and tag the release that carries the selection model, modes and the four-arm set, per
`docs/releasing.md` and `docs/qualification-runbook.md`, with the native cases the switches and modes
touch run and recorded. It is last in epic #552's dependency order [Source: #552] and is blocked by every other issue in
its milestone.
[Source: https://github.com/JakeSelby/agent-harness/issues/563]

## Acceptance criteria

1. **Given** the frozen commit, **when** `scripts/release_preflight.py` runs, **then** it is clean.
2. **Given** the qualification round, **when** its record is written, **then** it lists every case run
   and every case skipped, by name.
3. **Given** `compatibility/catalog.json`, **when** it is read, **then** it states per runtime whether
   switches are enforced or advisory.
4. **Given** the tag, **when** it is cut, **then** it matches the milestone.
