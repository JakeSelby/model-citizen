# AH-B145 — Offline rule detection skips a one-policy pair's reference and treatment streams

## Reproduction

1. Take a stored one-policy pair set whose streams are named `<task>-bare-<rep>.json`, `<task>-reference-<rep>.json` and `<task>-treatment-<rep>.json`.
2. Run `python3 scripts/cost_bench.py detect --raw <that directory>`.
3. Observed: `detected over 1 run(s)`; `detections.jsonl` holds rows for the bare arm only. The reference and treatment streams are skipped without a word.

## Root cause

`cmd_detect` passed `ARMS` (`bare`, `harness`, from `scripts/replay_arms.py`) to `replay_detect.detect_dir`, whose `parse_name` accepts only a file named for one of the arms it is given. A pair's arms are `replay_pair.ARMS` (`bare`, `reference`, `treatment`), so its harness-side streams never matched. `detect --backfill` was not affected: `detect_rows` builds each stream name from the arm the result row declares.

## Acceptance criteria

1. **Given** a `--raw` directory holding a pair's bare, reference and treatment streams, **when** `detect --raw` runs, **then** `detections.jsonl` carries read rows for all three arms and the command reports 3 runs.
2. **Given** a stored pair set with a `results.jsonl` declaring those three arms, **when** `detect --backfill` runs over its root, **then** its `detections.jsonl` carries read rows for all three arms.
3. **Given** a bare-and-harness `--raw` directory, **when** `detect --raw` runs, **then** its rows are unchanged.

## Design

`cost_bench.DETECT_ARMS` is every arm a replay row can declare, `ARMS` then `replay_pair.ARMS`, de-duplicated in order, and `detect --raw` passes it to `detect_dir`. A `--raw` directory names no set and carries no `results.jsonl`, so the arm list cannot come from rows there; the union of the two schedules is the full vocabulary. `parse_name` still matches the arm from the right, so a hyphenated task id is unaffected. Rejected: reading arms from a nearby `results.jsonl`, which a `--raw` directory need not have. Unchanged: `--backfill`, live detection (`detect_saved`) and the history's harness-arm mechanisms.

## Regression test

`tests/test_replay_detect_pair.py` over the stored set `tests/fixtures/replay-detect/pair-set` (streams copied from that directory's `raw` fixtures). `test_detect_raw_reads_every_arm_of_a_pair` fails on the pre-fix code (only `bare` read); `test_detect_backfill_reads_every_arm_of_a_pair` pins criterion 2.
