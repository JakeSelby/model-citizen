## Acceptance criteria

1. **Given** the `superpowers` mode (#558), **when** the two superpowers arms are built, **then** each is a container arm like #559's, declaring the plugin and its version, with the install in its manifest.
2. **Given** a pair that differs by anything but its declared treatment, **when** a replay starts, **then** it is refused before launch, naming the difference (#1010, point 4).
3. **Given** four arms, **when** `replay --dry-run` runs, **then** it prints the schedule with the lead arm rotating across the four.
4. **Given** the docs, **when** `docs/benchmarks.md` is read, **then** it describes the four arms and the parity rule.
