## Goal

The Studio adds a server, a front-end toolchain, a draft workspace and a run store to a standard-library CLI. Run `bmad-architecture` with update intent to record the decisions every Studio story builds on, as ADs in the architecture spine, each with the alternatives it rejects:

1. **One core, two faces.** The Studio calls the same functions as the CLI (`posture.selection()`, `config_set`, lint, sync, usage) and re-implements no resolution, validation or write. Every mutating Studio action has a `citizen` equivalent, and the Studio shows it.
2. **A standard-library server on loopback.** Threaded `http.server` on the Python 3.9 floor, JSON over HTTP, and server-sent events for streams. Rejected: FastAPI with uvicorn, whose compiled dependencies cannot ship as vendored, platform-independent wheels (AD-21); a Node server, which needs Node at runtime and a second implementation of the core.
3. **Locked to its launcher.** Loopback only; a per-launch token exchanged for an HttpOnly, SameSite=Strict cookie; a Host allowlist against DNS rebinding; Origin and CSRF checks on every write; a strict content security policy; no CORS; secrets redacted; file access confined to known roots. The HTTP API is private to the bundled UI and the CLI is the agent surface, so the API is not public surface under PRD §7.
4. **React, TypeScript and Vite, shipped as a committed bundle.** A single-page app built from a pinned lockfile, with its bundle committed so a curl install needs no Node; npm is a contributor build tool. This amends AD-21: bundled third-party code enters only after a licensing review, recorded in `third-party.json`. Rejected: server-rendered HTML with htmx (no build step, but weak for a streaming log, a diff editor and interval charts); Svelte or Solid (smaller bundles, thinner ecosystems for the editor, charts and accessible primitives); Electron or Tauri (signing and packaging for no gain over a loopback tab).
5. **Drafts are managed worktrees.** One worktree per draft, a checkpoint commit per save, and configuration edits as a config file inside the draft. Only the governed apply writes live configuration, a primitive root or projections (AD-3).
6. **Files stay the system of record.** Native result files and the ledgers stay authoritative (AD-11). The run store is a SQLite index plus the runs the Studio launched, with a schema version, and can be rebuilt from the files.
7. **One instance per user.** A state file under the harness state home holds the port, pid and token (mode 0600) for detach, status and stop, and runs orphaned by a restart are recovered or marked, as role workers are.

## Acceptance criteria

1. Each decision is an AD in the spine with what it binds, what it prevents, its rule and the rejected alternatives.
2. AD-21's amendment states what may enter the bundle, how its licences are recorded, and how CI checks the bundle against its source.
3. PRD §7 names `citizen studio`, `citizen draft` and `citizen runs` as public surface and the HTTP API as private.
4. The reproducible-bundle spike's result is recorded under decision 4.
