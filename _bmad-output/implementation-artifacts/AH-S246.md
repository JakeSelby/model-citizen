## Story

As a harness maintainer, I want the bench extended to four arms and to layer swaps, so that one of our layers can be compared with an external equivalent in the same slot, everything else held fixed.

## Context and value

FR-58 puts four arms in v0.16.0. #559 and #560 deliver the two-arm path in v0.15.0; this extends them to four arms and adds PRD §1's third comparison, a layer swap: one of our layers against an external equivalent in the same slot, with everything else held fixed. It also carries the four-arm part of #562's docs.

Depends on #559, #560 and #800. Traces to FR-58, PRD §1 (comparison 3) and §9 (v0.16.0).

## Acceptance criteria

1. Given #559's built-profile arms and #560's live set, then both run with four arms, with pair parity checked for every pair.
2. Given a layer swap, then exactly one slot's holder differs between the two arms, and the parity check refuses a swap that changes anything else.
3. Given the four-arm result, then it is published with SM-2's intervals, whatever it shows.
4. Given the docs, then they describe the four arms and how to read a layer swap.
