## Story

As a developer, I want lint, budget and projection feedback while I hand-edit a rule, skill or stance, so that what I write passes the gate and fits the budget.

## Context and value

A code editor for module text in a draft, with the findings `citizen lint` would report shown inline as the developer types (personal strings, secret patterns, the always-loaded budget, broken links), the token delta for each runtime, and a preview of the projected files Claude Code and Codex will load.

## Acceptance criteria

1. Given a secret pattern typed into a rule, then the editor marks the line with the lint finding before save, and save is refused with the reason.
2. Given an edit that pushes the always-loaded total over its cap, then the budget meter shows it and names the cap.
3. Given a file that changed on disk under an open editor, then the editor shows a conflict and never overwrites the newer file silently.
4. Given a save, then the lint result in the editor equals `citizen lint` on the draft, in tests.
