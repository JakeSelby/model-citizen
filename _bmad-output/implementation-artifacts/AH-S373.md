## Story

As a solo or small-team agentic developer, I want a Stances page showing each stance variant's effect over the period it was selected, so that I can compare variants on my own data.

## Context and value

Plan step 4. Reads selection plus `selection_editing`, one row per variant period from AH-S369. Target artboards `Stances.dc.html` and `StancesSettings.dc.html`.

## Acceptance criteria

1. **Given** stance selections over time, **when** the Stances page opens, **then** it shows one row per variant period.
2. **Given** the Settings tab, **when** a variant is changed, **then** the edit goes through `selection_editing` as a draft.
3. **Given** the page's route, **when** its API test runs, **then** it asserts period-stamped rows, the response shape, auth enforcement and error cases.
4. **Given** the page, **when** design-judge scores it against its round-3 artboard, **then** the score is at least 7, and node tests and an e2e flow cover it.

## Design

### Approach

- Efficacy rows per variant period; Settings over `selection_editing`.

### Decisions and alternatives

- **Read at page load from existing logs:** no hook-side recording (epic scope). Rejected: new recording for this page.

### Do not implement

- Changes to other Harness pages; new hook-side logging.
