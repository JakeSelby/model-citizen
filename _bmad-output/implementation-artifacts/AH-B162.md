## Reproduction

1. Price a Claude Code session that ran on `claude-opus-5-5` with `harness usage`.
2. `policy/prices.json` names `claude-opus-5` but not `claude-opus-5-5` or `claude-sonnet-5-5`,
   so `pricing.price_for` returns None and the row is unpriced. A session whose `by_model`
   breakdown named the unpriced model beside one listed in `models` fell back to its totals and
   was charged entirely at the listed model's rate.

## Root cause

The table was last read on 2026-09-21, before Opus 5.5 and Sonnet 5.5 were listed. Nothing
checked that a model id appearing in a recorded stream resolves to an entry. Separately,
`row_cost` fell back from an unpriceable `by_model` breakdown to the row's totals, contrary to its
own docstring ("priced from it and from nothing else").

## Acceptance criteria

1. **Given** the shipped table, **when** `claude-fable-5-1`, `claude-opus-5-5`,
   `claude-sonnet-5-5` or `claude-haiku-4-5-20251001` is priced, **then** it resolves to an entry
   carrying the rates on Anthropic's pricing page with its `source` URL and `as_of` date.
2. **Given** any JSON or JSONL fixture under `tests/fixtures`, **when** it names a model id that is
   not a declared placeholder, **then** that id has a price, or a test fails naming it.
3. **Given** a row whose model, or one part of whose breakdown, is unpriced, **when** it is
   priced, **then** the result is None (unknown), never zero and never a sibling's rate.

## Design

Add `claude-opus-5-5` ($4 / $20, cache hits $0.20, 5-minute writes $5, 1-hour $8) and
`claude-sonnet-5-5` ($2 / $10, $0.20, $2.50, $4), read from
https://platform.claude.com/docs/en/about-claude/pricing on 2026-10-03. Fable 5.1 and the dated
Haiku 4.5 id already resolve. `row_cost` returns the breakdown's result whenever a breakdown is
present. Rejected: prefix matching, which would bill Opus 5.5 at Opus 5's higher rate.
`scripts/cost_bench.py` is out of scope here.

## Regression test

`tests/test_prices_cover_streams.py`: every fixture stream model is priced, the scan names a
missing id, each current id prices at the page's figures, and an unpriced model or breakdown part
is None.
