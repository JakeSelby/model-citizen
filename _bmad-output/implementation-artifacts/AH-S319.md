## Story

As a developer, I want Claude Code's plugin evals in the Studio's run store, so that plugin and skill results sit beside the harness's own runs.

## Context and value

Claude Code ships its own efficacy tool: per Anthropic's plugin-evals docs, `claude plugin eval` runs cases with and without a plugin, grades them (a regex, a tool-called check or an LLM rubric), and writes an aggregate result and an HTML report. It measures plugins and skills, not instruction files. It was the only first-party efficacy tool the 2026-09-26 field check found (#1005). Importing its reports puts plugin and skill evals beside the harness's own runs, in the same history and comparison views.

## Acceptance criteria

1. Given a result file from `claude plugin eval`, when `citizen runs reindex` runs, then it is imported as a run with its cases, its two arms (with and without the plugin) and its scores.
2. Given a result file in an unknown format version, then the import skips it and reports it, and never guesses.
3. Given an imported run, then its detail page links the original HTML report.
