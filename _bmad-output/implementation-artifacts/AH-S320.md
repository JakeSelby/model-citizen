# AH-S320 — Every cost, efficacy or system-change test is a controlled, pre-registered experiment in fresh containers

## Story

As the maintainer, I want every benchmark, pilot, replay, A/B, ad hoc eval or test of cost,
efficacy or a change to the system to run as a controlled, pre-registered experiment in fresh
containerized installs, so that every claim Model Citizen makes rests on an experiment that
isolates exactly the named components.

## Context and value

Model Citizen is a diagnostic tool, so its claims are only as good as the experiments behind them.
Before this story the evidence standard's section 3 allowed a run without a container if it said
so, and the replay's harness arm falls back to the live profile when no profile is named (#428).
An arm that inherits host state measures the host, not the named components.

## Acceptance criteria

1. **Given** `docs/evidence-standard.md`, **when** it is read, **then** it carries the eleven-point
   protocol from #1010, makes containers mandatory, and has no allowance for a run without one;
   `AGENTS.md` carries an operative line pointing to it that covers ad hoc evals as well as
   releases.
2. **Given** the replay runner or any other eval entry point, **when** an arm is outside the
   protocol (host `HOME`, live profile, inherited hooks, a manifest that differs from the
   declaration, or no pre-registration for a non-exploratory run), **then** it refuses to start,
   with tests.
3. **Given** the same arm built twice from its recorded inputs, **when** a dry run compares them,
   **then** the two manifests are equal.
4. **Given** #559, **then** it supplies the Linux containers from the qualification image; the
   macOS VM target stays on v0.15.0.

## Design

### Approach

Two passes. Pass 1 writes the protocol into the evidence standard, points `AGENTS.md` at it,
documents where a pre-registration lives and which fields are checked, and adds the
pre-registration gate as `scripts/experiment_protocol.py`, a standard-library module every eval
entry point calls. `scripts/cost_bench.py replay` gains `--pre-registration <path>` and
`--exploratory`, one call to the gate in `cmd_replay`, the gate's stamp on every row, and no history
row from an exploratory run.

Pass 2 builds on #559's containers. Its seam, `replay_arms.admit(record)`, runs
`ADMISSION_CHECKS` once per arm before anything launches; this story adds four checks there: the
manifest matches the declaration (Claude Code version, agent clients, harness commit and checkout),
every configuration entry comes from a declared component, no recorded input names a host path,
and the run is pre-registered or exploratory (the replay passes its stamp as `protocol`).
`run_command` refuses any mount or variable that names the host home, this checkout or an ambient
`CLAUDE_CONFIG_DIR`, so every launch is covered, not only the scored ones. `summarise` and
`per_task` count an errored run as a failed attempt with its cost (point 10).

### Decisions and alternatives

- The gate lives in its own module rather than inside `cost_bench.py`, because #559 rewrites the
  replay's arm code at the same time and every other eval entry point needs the same check.
- Default taken: a plan lives at `benchmarks/preregistrations/<YYYY-MM-DD>-<slug>.md`, and its
  file-name date must equal its **Date registered** field, because a date in both places is the
  cheapest mechanical check that the plan is dated.
- Default taken: the gated fields are Question, Date registered, Primary hypothesis, Primary metric,
  Tasks, Trials per task and arm, and the Decision rule section, because those are the five items
  #1010 names plus the date; the other sections remain required by the evidence standard.
- Default taken: a plan with uncommitted changes is refused, because a plan is fixed by its commit.
- Default taken: `--verify-tasks` needs no pre-registration, because it calls no model and runs no
  arm.
- Default taken: a comparison on real sessions (item 11) is exploratory, because it cannot run in
  the protocol's containers.
- Decided by the owner on 2026-09-27: a timed-out run with no readable cost is charged at the
  per-run cap. Another errored run with no readable cost leaves its arm's cost per passed task
  undefined, because no bounded spend can be recovered from its row.
- Default taken: a harness arm's configuration entry is declared when it is a directory, a link into
  `/opt/model-citizen`, or one of the two files the sync writes (`settings.json`,
  `CLAUDE.personal.md`), because the manifest records a file's hash, not its provenance.
- Default taken: host paths are the home directory, this checkout and an ambient
  `CLAUDE_CONFIG_DIR`, resolved, because the home directory holds the profile and the live checkout.
- Rejected: labelling rows exploratory by reusing `--change-note` or `--bucket`, which would mix the
  evidence label into free text.

### Do not implement

- Container builds, manifests and the macOS VM target (#559; the VM stays on v0.15.0).
- Any replay run or model call.

## Review findings

- CodeRabbit: the pre-registration stamp named the latest plan edit rather than the addition commit.
  It now uses the addition commit, refuses shallow history and tests a committed deviation entry.
- CodeRabbit: admission trusted a manifest's configuration summary without re-deriving it. It now
  compares that summary with the entries and refuses omissions or extra kinds.
- CodeRabbit: an isolated image HOME equal to the host HOME was mistaken for a host input. Manifest
  roots are no longer host-input strings; declaration values and link targets remain guarded.
