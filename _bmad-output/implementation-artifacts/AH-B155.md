## Reproduction

Run `python3 scripts/release_preflight.py` in a fresh clone of `main`: it reports that the `on_the_way` entry "Measured against bare" names #799, which is closed.

## Root cause

#799 closed on 2026-09-30 when the proof-bundle tooling merged, but the entry advertises the powered proof run, which is #560 and still open. `product.json` was not updated when #799 closed. [Source: scripts/release_preflight.py]

## Acceptance criteria

1. **Given** `product.json`, **when** the "Measured against bare" entry is read, **then** it names #560 and its title and line are unchanged.
2. **Given** the fixed tree, **when** release preflight runs in a fresh clone, **then** it reports no closed on-the-way issue.
3. **Given** the fixed tree, **when** `bin/harness generate --check` runs, **then** it passes.

## Design

Change only the entry's `issue` field from 799 to 560. Removing the entry was rejected: the measurement is still planned and advertised. The wording must not change.

## Regression test

`tests/test_release_upkeep.py::test_a_closed_on_the_way_issue_says_promote_or_remove` already covers the closed-issue check with recorded fixtures; no network-dependent test is added.
