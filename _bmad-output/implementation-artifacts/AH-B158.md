## Reproduction

Run the registered pilot command from `benchmarks/preregistrations/2026-10-01-power-pilot.md` with `--dry-run`. `scripts/experiment_protocol.py` refuses it: "the pre-registration leaves required fields unfilled: Decision rule". No trial has run.

## Root cause

The Decision rule wrote the literal `--have 7 <corrected long-task count> 5`. `PLACEHOLDER` (`<[^<>\n]+>`) in `scripts/experiment_protocol.py` reads it as an unfilled template slot, so `_first_filled_commit` finds no commit with a filled plan. Nothing in the test suite ran `missing_fields` over the committed plans, so the plan merged.

## Acceptance criteria

1. **Given** the pilot pre-registration, **when** `missing_fields` reads it, **then** it returns nothing, and the Decision rule keeps its meaning with no angle brackets.
2. **Given** the reword, **when** the Deviation log is read, **then** a dated 2026-10-02 entry records it as a wording fix made before any trial.
3. **Given** any `*.md` in `benchmarks/preregistrations/`, **when** the suite runs, **then** a test fails naming each file with an undated name or an unfilled required field.
4. **Given** the registered pilot command with `--dry-run`, **when** it runs, **then** the pre-registration check passes and the schedule prints.

## Design

Reword to `--have 7 N 5`, where N is the corrected long-task count; append a Deviation log entry. Add `tests/test_preregistrations.py`, which applies the runner's own `DATED_NAME` and `missing_fields` to every committed plan. Rejected: loosening `PLACEHOLDER`, which would weaken the check for every plan. The registered figures and command do not change.

## Regression test

`tests/test_preregistrations.py` reports `2026-10-01-power-pilot.md: Decision rule is unfilled` against a `git archive` copy of origin/main's plans and passes after the reword.
