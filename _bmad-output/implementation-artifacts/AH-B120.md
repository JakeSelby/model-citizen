# AH-B120 — Directed BMad prompt paths can evade spawn confinement after an em dash

## Reproduction

Run `spawn-confinement` on the frozen v0.14.0 source `1b84c424e7d678122844796e936ee638525d398a`
with Claude Code CLI 2.1.280 in Ubuntu 26.04 arm64. The model writes an unnamed BMad review brief
that names `_bmad/review-prompts/edge-case-hunter.md`, explains after an em dash that it contains
the layer's review instructions, then says "Follow those instructions exactly." The classifier
scores `(agents=0, directed=0, identifiers=1, phrases=0)`, so the native subagent runs unconfined.

## Root cause

`frameworks.SENTENCE` deliberately splits at an em dash. `_directed` then sees the identifier in
one segment, "it contains ... review instructions" in the next and the directive in the third.
Its continuation test accepts named instruction/file anaphors but not a bare `it`, so it stops
before reaching the directive. [Source: lib/harness_core/frameworks.py#_directed]

## Acceptance criteria

1. **Given** the exact qualification brief, **when** it is classified, **then** it maps to BMad's
   `code-review-layer` and constrained `reviewer` role.
2. **Given** an explanatory `it` clause after the prompt path, **when** it describes the file as
   instruction-like guidance and a later sentence follows those instructions, **then** the path
   reference continues to that directive.
3. **Given** an unrelated `it` clause, a prompt-file edit or a passing review mention, **when** it
   is classified, **then** it is not refused as framework work.
4. **Given** the fixed source, **when** the repository gate and required native qualification run,
   **then** the tests pass and both required targets carry passing evidence before release.

## Design

Add a narrow continuation signal for a bare `it` only when the same segment contains an
instruction-like noun. This preserves the existing three-segment reach while keeping an unrelated
pronoun too weak. Do not change the refusal text, descriptor schema, corroboration floor, edit
vetoes or any non-directed recognition signal. Rejected: treating any `it` as an anaphor, which
would reconnect unrelated clauses; removing em-dash splitting, which would weaken clause bounds.

## Regression test

Add the exact em-dash wording to `DIRECTED` in `tests/test_framework_directed_identifier.py`; it
fails before the fix and passes after it. Add an unrelated `it` chain to `UNDIRECTED` to protect
the false-positive boundary.
