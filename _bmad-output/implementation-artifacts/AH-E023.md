## Goal

Everything the CLI can change, the Studio changes in a draft: the mode, stance variants and switches,
identity, preferences and integrations, and module text, plus new and forked modules. A draft is
reviewed as a diff with its lint status and budget delta, applied through the CLI's own locks, checks
and journal, and rolled back in one step. `citizen draft` gives agents the same loop.

Completion is observable: after any edit the live checkout, the live config and every projection are
byte-identical to before; an applied draft equals running the CLI commands the Studio shows; and a
rollback restores the prior state byte for byte.

## Scope and requirement coverage

**In scope:**

- Drafts as managed worktrees with checkpoint commits, and `citizen draft` (AH-S290).
- Editing the selection (AH-S291), settings (AH-S292) and module text (AH-S293), and adding new and
  forked modules (AH-S294).
- Review and apply (AH-S295), and rollback (AH-S296).

**Out of scope:**

- Testing a draft, which is AH-S308 in AH-E025.
- Editing a core module in place: a stable install fast-forwards on update, so a local edit would
  conflict [Source: scripts/install.sh]. Forks and contribution branches replace it.
- Opening a pull request from the Studio: apply hands over a branch and the commands, and the
  repository's own rules govern the pull request.
- Automatic stance changes (PRD §8).

**Requirement coverage,** against the PRD's §4.16 Studio:

- **FR-78 Tune in drafts:** AH-S290 to AH-S294.
- **FR-79 Apply and roll back through the governed path:** AH-S295, AH-S296.

## Architecture slice

- **AD-3 Reversible configuration ownership:** apply and rollback go through the ownership journal.
- **AD-2 One resolver:** every edit is checked by the functions `config_set` uses, never a copy of them.
- **AD-16 and AD-18:** apply takes the same lock as sync and respects write-intent claims.
- **AD-22 Modules declare a manifest:** new and forked modules pass the manifest checks.
- **AH-T036's draft decision:** one managed worktree per draft, a checkpoint commit per save.
