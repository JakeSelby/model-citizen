Every paid Studio run and every draft apply, rollback or recovery started from `citizen` now needs a person's confirmation. The command grader asks about each one in every permission mode, and in `auto` and `bypassPermissions` refuses it with an approval code that covers that exact command once; the confirm marker does not count. The CLI refuses a spend or apply that arrives without the one-use grant the approval channel or the Studio's own dialog writes, or a `yes` typed at a terminal outside an agent runtime, so a confirmation token, revision, flag or environment variable alone no longer starts one. Activity records each confirmed CLI spend or apply.
