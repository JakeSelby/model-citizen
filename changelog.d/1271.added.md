Every paid Studio run and every draft apply, rollback or recovery now needs a person at the Mac. The command grader asks about each one started from `citizen` in every permission mode, refusing it in `auto` and `bypassPermissions` with an approval code for that exact command; the confirm marker does not count. Then the CLI, and the Studio's own spend routes, check the request and then ask macOS for Touch ID or the login password, in a dialog that names the spend or the draft, before they spend or apply, and refuse with `person_confirmation_required` when that is declined or cannot be shown (off macOS, without a desktop session, or in Codex). A confirmation token, revision, flag, file or environment variable alone no longer starts one. Activity records each confirmation, even with the decision log switched off.
