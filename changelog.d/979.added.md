An applied draft can now be rolled back in one step, from Activity or with `citizen draft rollback
<apply-id>`: it previews the reverse diff, then restores the configuration keys and personal-root
files the apply wrote, from the apply journal, and runs `citizen sync` and the doctor checks under
the same locks. With nothing changed since, the configuration, the root and the projections return
byte for byte. A later apply still in effect that touched the same keys or files, or a later hand
edit, refuses the rollback by name and is kept. Each rollback is journalled and shown in Activity,
linked to the apply it reversed, and can itself be rolled back.
