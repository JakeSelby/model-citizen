Studio can now review a draft against its base, with every changed file and configuration key, its
lint and resolution checks, the context-budget delta and the exact commands, then apply it under the
sync lock: the draft's personal root moves to `~/.config/agent-harness/personal-primitives`, each key
goes through `citizen config set`, then `citizen sync` and the doctor checks run. Apply refuses a
draft with findings, a held lock (naming its holder) or an in-place core edit, which gets a fork and
a contribution branch instead. `citizen draft review|apply` do the same.
