`harness usage` now prices role-worker runs. A Claude Code worker is launched by a model alias
such as `opus`, and its usage row carried that alias, which matches no price, so most worker runs
reported no cost. The row now names the full model id the run used, read from the run's own result
envelope, and a helper model that ran beside it is charged at its own rate. Runs recorded before
this release reprice on the next session's sweep.
