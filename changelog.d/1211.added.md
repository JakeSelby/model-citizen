Studio can now pre-register a draft test before running it, as an opt-in. The registration fixes
the draft's checkpoint, its base commit, the whole task set and pack, the trials per task, the model
and the change worth detecting, is filled in from the engine's pre-registration template and checked
by its gate, and is refused when the trials cannot detect that change at the repository's declared
variance, with the engine's minimum detectable effect and the trials that would. A registration
backs one run: the run that matches it exactly may read "helped" or "worse" by the evidence
standard's decision rule, any deviation leaves it exploratory, a second run under it is refused,
and any edit to the draft makes it stale. `citizen draft test NAME --register` takes the same path.
