Studio can now pre-register a draft test before running it, as an opt-in. The registration fixes
the draft's checkpoint, its base commit, the task set and pack, the trials per task, the model and
the change worth detecting, is written in the engine's pre-registration format and checked by its
gate, and is refused when the trials cannot detect that change, with the engine's minimum
detectable effect and the trials that would. A run that matches its registration exactly may read
"helped" or "worse" by the evidence standard's decision rule; any deviation leaves it exploratory,
and any edit to the draft makes the registration stale. `citizen draft test NAME --register` takes
the same path.
