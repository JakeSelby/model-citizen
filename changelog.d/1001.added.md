The Studio now has a user guide, `docs/studio.md`, linked from the README, getting started and usage. It covers starting the Studio with `citizen studio` and its security
model (loopback only, launcher sign-in, session cookie, CSRF and Origin checks, a strict content
security policy and redacted secrets); drafts through `citizen draft`, including review, apply,
rollback and recover; the first run; runs and their targets, spend guard, native acceptance, live
replay, evaluation tiers and plugin eval import through `citizen runs`; testing and pre-registering
a draft with `citizen draft test`; comparing runs with `citizen runs compare`; and the trends, rule
health and spend reports; and the headless agent loop, `citizen runs replay|eval|native|draft-test`,
`citizen reports trends` and the studio-loop skill. A test runs `--help` for every command the
guide names, including continued code lines, and checks each flag it shows, in code or in prose.
