Codex role workers (`harness role run <role> --runtime codex`) now record what they spent, so
`harness usage --by role` counts and prices them. The adapter read the token totals in the shape
Codex writes to its rollout transcripts, but `codex exec --json` reports them as the `usage`
object on its `turn.completed` event, so every completed Codex worker was recorded with unknown
totals and left unpriced. Runs recorded before this fix stay unpriced.
