Studio can now test a draft against the commit it was based on. Both run as one live replay
pair on the same tasks, model, trials, evaluator pack and caps, and before anything starts the
Studio says whether the trials can detect the change you name, from the engine's minimum
detectable effect, and offers the number of trials that would. The draft's page keeps the latest
verdict for each checkpoint with the engine's Cost-of-Pass and pass-rate readings, the spend and a
link to the full comparison, and marks a verdict stale once the draft changes. A draft runs
unregistered, so a draft test is exploratory and never says the draft helped; "helped" is shown
only for a citable comparison that meets the evidence standard's decision rule on the engine's
intervals, and a draft still at its base commit is refused.
`citizen draft test NAME` prints the same verdicts.
