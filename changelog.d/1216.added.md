Replay rows now say what the spawn hooks did to each spawn: `spawn_briefs` records whether each
brief a subagent received carried the return bound and soft budget `brief-guard` appends, and
`workflow_launch_hooks` whether each `Workflow` launch's agents met the spawn hooks, both null
when the stream cannot tell. A pack task marked `first_wave` stops once its first wave of spawns
is out, and `ended_by` names the bound that ended the trial. A pack workspace can fetch a
permissively licensed skill at a pinned commit and digest, so both arms are offered it.
A task can set `allow_web_search: true` to leave WebSearch enabled in both arms (WebFetch stays
denied), and the micro tier can score a Workflow task on its `workflow_launches`.
