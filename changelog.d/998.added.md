Agents can run the whole Studio loop from `citizen` with `--json`: every Studio action now names a command that parses and prints the same object the Studio sends, and a test fails a route whose command does not. Paid replays, eval tiers, native acceptance and draft tests gained `citizen runs replay|eval|native|draft-test ACTION --request FILE`, which run the Studio's own admission, so their spend previews, confirmation tokens and target refusals are the Studio's. `citizen runs start` now refuses those paid suites and names the command to use, `citizen doctor --json` prints the Studio Overview, and `citizen catalog --library --json` prints the Studio Library. A new `studio-loop` skill teaches the loop, keeps spend and apply on the user's go, and hands over the `url` from `citizen studio --detach --json` instead of a screenshot.
