Remote Control bridge sessions now get the one-time stop block at the context hand-off point. A
bridge session reports the same `sdk-cli` entrypoint as a headless `claude -p` run, which is
exempt so a replay trial is not given an extra turn, so bridge sessions ran far past the hand-off
point with no block. The hook now tells them apart by `CLAUDE_CODE_ENVIRONMENT_KIND=bridge`, which
the bridge sets and a headless run never has.
