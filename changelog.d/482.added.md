Every replay row now records the loaded surface the CLI itself reports, the `init` event's counts
of skills, agents, slash commands, tools, MCP servers and memory paths, and the first call's whole
input as `first_call_context`, and `backfill` derives them for sets already on disk. A set stops
when a run's surface differs from its arm's first run, unless `--allow-surface-drift`, which runs
on and stamps every row. Before launch, the replay refuses a pair of arms that differ by anything
but the harness. The new `--effort` option pins the reasoning effort every arm launches at: it is
recorded in each arm's declaration and on every row, and a run whose stream reports another
effort stops the set.
