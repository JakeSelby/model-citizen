# Cost stance: balanced

Session effort runs **medium**, fan-out stays at six subagents or fewer, fast mode is off unless asked, and a task
ends with `/clear`, not `/compact`. Past 160,000 tokens of context a call costs more; the feed says so. **Past 400,000,
about 3.3× the cost per call, the turn's end is blocked once: write the handoff, then start a fresh session.** Spend
the effort dial on judgment work and keep gathering cheap. The table also prices each role and band: class, effort,
soft budget. Tier comes from `delegation`; this one sets how much. Cache rules: `cache-hygiene.md`.
