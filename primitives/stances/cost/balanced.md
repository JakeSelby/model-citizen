# Cost stance: balanced

Session effort runs **medium**, fan-out stays at six subagents or fewer, and fast mode is off unless asked. Past 160,000
tokens of context a call costs more; the feed says so. **At 360,000 the turn's end is blocked once to save the handoff;
at 400,000, about 3.3× the cost per call, the context resets, is reseeded from it and work carries on.** A finished task
refreshes the handoff; a desktop session clears itself when nothing is open. Spend effort on judgment, gather cheap. The
table prices each role and band: class, effort, soft budget. Tier comes from `delegation`. Cache: `cache-hygiene.md`.
